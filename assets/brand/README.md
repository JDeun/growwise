# GrowWise brand assets

GrowWise의 브랜드 심볼은 **열린 책 + 새싹**을 하나의 형태로 결합한다. 책은 축적되는 기록·자료·배움을, 새싹은 아이의 장기적인 성장과 부모의 돌봄을 의미한다.

## Core palette

- Sage Green `#2F8F6B`
- Leaf Green `#A7D7A0`
- Warm Off White `#FBF9F6`
- Ink `#2B2A28`
- Stone `#9CA3AF`

## Usage

- `growwise-symbol.svg`: 앱 아이콘, favicon, GitHub avatar용 기본 심볼
- `growwise-logo.svg`: README, About, 온보딩용 가로형 로고
- 로고에 AI spark, chatbot bubble, robot/brain motif를 추가하지 않는다.
- 왜곡, 과도한 gradient, neon/glow, 점수/게임 보상형 배지를 조합하지 않는다.
- 작은 크기에서는 워드마크 대신 symbol-only를 사용한다.

브랜드 시각 언어의 전체 원칙은 `docs/design-system.md`를 따른다.
