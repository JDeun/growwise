# GrowWise

GrowWise는 **우리 아이가 요즘 무엇에 관심 있는지 기억하고, 오늘 같이 해볼 일을 준비해 주는 가족용 교육 앱**입니다.

아이의 질문·관심·이전 활동·부모 관찰을 짧게 남기면 그 기록이 다음 활동의 출발점이 됩니다. 매번 챗봇에게 아이의 상황을 처음부터 설명하거나, 부모가 놀이와 학습 자료를 다시 검색할 필요를 줄이는 것이 목표입니다.

```text
아이의 질문과 경험
        ↓
짧게 기록
        ↓
최근 맥락과 연결
        ↓
오늘 함께할 활동
        ↓
활동 후 한 줄 기록
        ↓
다음 활동으로 이어짐
```

GrowWise에서 중요한 것은 기록의 양이나 그래프가 아니라 **기록이 실제 다음 행동으로 이어지는가**입니다.

> GrowWise는 아이를 평가하거나 점수를 매기는 프로그램이 아닙니다.  
> 부모가 아이를 이해하고 다음 경험을 준비하도록 돕는 기록·자료 도구입니다.

---

## 오늘 무엇을 할지 결정하는 데 도움을 줍니다

예를 들어 아이가 산책 중 “민들레 씨앗은 왜 날아가?”라고 물었다면 그 한 문장을 남겨둘 수 있습니다. 다음에 GrowWise를 열었을 때는 과거의 질문과 최근 관심을 바탕으로 **“어떤 모양의 씨앗이 더 멀리 갈까?”** 같은 짧은 활동으로 이어갈 수 있습니다.

활동이 끝난 뒤 “길쭉한 종이가 더 멀리 갈 거라고 예상했다”처럼 한 줄만 남겨도, 그 결과는 이후 활동을 준비하는 맥락이 됩니다.

> **기록 → 다음 활동 → 실제 경험 → 다시 기록**
>
> 이 반복이 GrowWise의 핵심 제품 흐름입니다.

## 무엇을 할 수 있나요?

### 아이의 배움과 일상을 기록합니다

독서, 놀이, 학교·학원 학습, 질문, 관심사, 어려웠던 점, 사진 활동 등을 한 아이의 장기 기록으로 남길 수 있습니다.

### 오늘 할 활동을 만듭니다

아이의 연령·학년·관심사와 이전 기록을 참고해 다음과 같은 자료를 만들 수 있습니다.

- 생활 활동 가이드
- 독서 활동
- 영어 대화 카드
- 수학 놀이
- 과학 탐구
- 글쓰기·말하기 활동
- 탐방·여행 활동지

기본 화면에는 실제로 필요한 활동 내용만 보여 줍니다. 부모용 상세 안내, 교육과정, 출처와 근거는 **원할 때만 펼쳐서 확인**할 수 있습니다.

### 활동 결과를 다음 기록으로 이어갑니다

활동이 끝난 뒤 한 줄만 남겨도 됩니다.

> “얼음이 녹는 모습을 오래 보더니 왜 물이 생겼는지 물었다.”

더 기록하고 싶다면 아이의 답변, 사진, 어려워한 점, 다음 활동 등을 추가할 수 있습니다. 이 기록은 이후 자료와 추천을 준비할 때 다시 활용됩니다.

### 사진도 기록으로 남길 수 있습니다

사진을 저장하고 부모가 직접 관찰 내용을 적을 수 있습니다. 로컬 AI를 사용하면 사진 내용을 바탕으로 기록 초안을 보조할 수도 있습니다.

### 기록을 검색하고 다시 연결합니다

예전에 무엇을 좋아했는지, 어떤 활동을 어려워했는지, 특정 주제로 어떤 기록이 있었는지 찾아볼 수 있습니다. AI가 꺼져 있어도 기본 검색과 기록 기능은 사용할 수 있습니다.

### 백업하고 복원합니다

아이 기록과 자료를 로컬에 보관하고 백업 파일을 만들거나 복원할 수 있습니다.

## 처음 시작하기

GrowWise의 첫 사용 흐름은 단순하게 유지합니다.

```text
1. 아이 등록
   닉네임 + 생년월일

        ↓

2. 첫 활동 만들기
   주제 입력 → 활동 내용 확인 → "이 활동 사용하기"

        ↓

3. 활동 후 기록
   한 줄 기록 저장

        ↓

4. 다음 활동
   지금까지 쌓인 기록을 다시 활용
```

생년월일을 입력하면 GrowWise가 현재 연령과 한국 학년 경계를 계산해 교육 단계와 적용 교육과정을 판단합니다. 생년월일을 입력하고 싶지 않다면 월령이나 학년을 직접 입력할 수도 있습니다.

자세한 화면별 사용법은 **[사용자 가이드](docs/user-guide.md)**를 참고하세요.

## 30초 미리보기

설치하기 전에 어떤 제품인지 먼저 보고 싶다면 **[제품 둘러보기](docs/product-tour.md)**에서
가상의 아이 기록으로 전체 흐름을 볼 수 있습니다.

### 활동지는 이렇게 보입니다

```text
얼음은 어디에서 더 빨리 녹을까?

오늘의 목표
두 장소의 얼음 변화를 관찰하고
처음 예상과 실제 결과를 비교해 설명해 봅니다.

예상 시간  15~20분
준비물      얼음 2개 · 접시 2개 · 타이머

시작하기
"어느 쪽 얼음이 먼저 작아질까?"
"왜 그렇게 생각했어?"

관찰하기
1. 하나는 햇빛에, 하나는 그늘에 둡니다.
2. 5분마다 크기와 접시의 물을 비교합니다.
3. 처음 예상과 무엇이 달랐는지 말해 봅니다.

막힐 때 힌트
"두 장소 중 어디가 더 따뜻할까?"
```

부모용 상세 안내, 교육과정, 출처는 기본적으로 접혀 있고 필요할 때만 확인합니다.

### 대화는 이런 식입니다

> **부모:** 최근 한 달 동안 민서가 자연과 관련해서 무엇에 관심을 보였어?
>
> **GrowWise:** 최근 기록에서는 식물의 이동, 얼음의 상태 변화, 공룡과 멸종 관련 질문이
> 반복되었습니다. 다음 활동으로는 최근 민들레 관찰에서 이어지는
> **“씨앗은 어떻게 멀리 갈까?”** 같은 탐구를 연결할 수 있습니다.
>
> 근거: 최근 관찰 기록 · 얼음 활동 결과 · 공룡 독서 기록

대화는 새 사실을 대신 만들어 내는 기능이 아니라, **이미 저장된 기록을 다시 찾고 연결하는 도구**입니다.

### 활동 후에는 한 줄이면 됩니다

```text
오늘 활동은 어땠나요?

얼음이 녹으면서 생긴 물을 보고
"얼음 안에 물이 들어 있었어?"라고 물었다.

[ 한 줄 기록 저장 ]
```

더 남기고 싶을 때만 아이 질문, 흥미, 어려움, 다음 활동, 사진 등을 펼쳐서 추가합니다.

> 위 예시는 실제 아동 데이터가 아닌 가상 데모입니다.
> 전체 화면별 예시는 **[GrowWise 제품 둘러보기](docs/product-tour.md)**에서 확인할 수 있습니다.

## 화면 구성

GrowWise는 다음 작업공간으로 구성됩니다.

| 화면 | 하는 일 | 예시 |
| --- | --- | --- |
| **대시보드** | 최근 기록과 오늘 할 일을 확인 | “최근 민들레 관찰에서 이어갈 활동” |
| **아이 프로필** | 아이 정보와 장기 흐름 확인 | 최근 관심: 공룡 · 식물 · 얼음 |
| **학습 기록** | 학습·관찰·활동 결과 기록 | 독서, 학교·학원, 과제, 일기 |
| **자료실** | 활동 자료 만들기, 참고 자료 관리, 자료 찾기 | “얼음은 어디에서 더 빨리 녹을까?” |
| **사진첩** | 사진 중심 활동 기록 | 블록 놀이 사진 + 부모 관찰 |
| **대화하기** | 저장된 기록과 자료를 바탕으로 질문·검색 | “최근 수학에서 어려워한 게 뭐였지?” |
| **백업 및 복원** | 데이터 백업, 내보내기, 복원 | 가족 기록 ZIP 백업 |
| **설정** | 가족 프로필과 앱 상태 관리 | 생년월일·학년·AI 상태 |
| **도움말** | 사용법과 데이터 원칙 확인 | 첫 활동, 개인정보, 백업 안내 |

## AI가 꼭 필요한가요?

**아니요.**

GrowWise의 핵심 기록과 자료 관리 기능은 AI 없이도 사용할 수 있습니다.

AI가 없어도 가능한 기능:

- 아이 프로필과 기록 저장
- 사진과 부모 메모 저장
- 기본 검색
- 공식 교육과정 정보 연결
- 활동 관리
- 기본 학습 자료 생성
- 백업과 복원

로컬 AI를 설치하면 다음 기능이 더 풍부해집니다.

- 기록 정리와 태깅 보조
- 검색과 질문 응답 보조
- 학습 자료 문장과 개인화 보강
- 사진 내용 이해와 기록 초안
- 저장된 기록 사이의 맥락 정리

AI가 실패하거나 꺼져 있어도 부모가 남긴 원본 기록은 먼저 로컬에 저장됩니다.

---

## AI를 사용하려면

GrowWise의 기록·검색·활동 관리 기능은 AI 없이도 사용할 수 있습니다. AI 보조 기능을 사용하고 싶다면 **Ollama를 한 번 설치한 뒤 GrowWise의 설정 화면에서 준비 상태를 확인**하는 방식을 권장합니다.

Ollama가 실행 중이면 GrowWise가 연결 상태와 필요한 모델 준비 여부를 확인합니다. 모델이 없다면 설정 화면에서 **기본 AI 준비**를 선택해 필요한 모델을 받을 수 있습니다. 일반 사용자는 모델 이름이나 환경변수를 직접 다룰 필요가 없습니다.

GrowWise는 텍스트와 사진 이해를 위해 **같은 Qwen 3.5 멀티모달 모델 하나를 기본적으로 공유**합니다. 별도 비전 모델을 추가로 받을 필요가 없습니다. 검색 보강용 임베딩 모델만 별도로 사용합니다.

Desktop은 하드웨어를 보고 기본 모델을 자동 선택합니다.

| 환경 | 자동 선택 예시 |
| --- | --- |
| 저사양 PC / 8 GB급 메모리 | `qwen3.5:2b` |
| 16 GB급 일반 PC | `qwen3.5:4b` |
| 24–32 GB Apple Silicon 또는 충분한 GPU | `qwen3.5:9b` |
| 48 GB Apple Silicon 또는 24 GB급 NVIDIA VRAM | `qwen3.5:27b` |
| 64 GB Apple Silicon 또는 32 GB급 NVIDIA VRAM | `qwen3.5:35b` |

Apple Silicon에서는 통합 메모리를, NVIDIA 환경에서는 감지 가능한 VRAM을 우선 참고합니다. 가속기를 확실히 감지하지 못한 PC에서는 시스템 RAM만 크다고 27B/35B를 자동으로 선택하지 않습니다. 검색 보강에는 `nomic-embed-text`를 사용합니다.

일반 사용자는 **설정 → AI 보조 기능**에서 준비 상태를 확인하는 것을 권장합니다. 명령줄로 직접 설치하려는 고급 사용자는 [로컬 AI 설정 가이드](docs/local-ai-setup.md)를 참고하세요.

컴퓨터 사양이 낮거나 더 큰 모델을 사용하고 싶다면 모델을 바꿀 수 있습니다.

| 사용 가능한 메모리* | 권장 텍스트 모델 | 대략적인 모델 파일 크기 |
| --- | --- | ---: |
| **8 GB** | `qwen3.5:2b` | 약 2.7 GB |
| **16 GB** | `qwen3.5:4b` | 약 3.4 GB |
| **24–32 GB** | **`qwen3.5:9b`** | 약 6.6 GB |
| **48 GB** | `qwen3.5:27b` | 약 17 GB |
| **64 GB 이상** | `qwen3.5:35b` | 약 24 GB |

\* 시스템 RAM, Apple Silicon의 통합 메모리, 또는 충분한 VRAM을 포함한 **보수적인 출발점**입니다. 운영체제와 다른 앱, 컨텍스트 길이, 사진 모델 동시 사용에 따라 실제 사용 가능 범위는 달라집니다.

저사양 컴퓨터에서는 로컬 AI를 설치하지 않고 GrowWise의 기본 기능만 사용하는 것도 가능합니다.

**Windows/macOS 설치 방법, 하드웨어별 자동 선택 기준과 고급 모델 설정은 [로컬 AI 설정 가이드](docs/local-ai-setup.md)**에 정리되어 있습니다.

## 내 아이의 데이터는 어디에 저장되나요?

GrowWise는 **local-first**를 기본 원칙으로 합니다.

- 아이의 기록과 자료는 로컬 컴퓨터에 저장됩니다.
- 사진 원본도 로컬 관리 영역에 저장됩니다.
- AI를 로컬 Ollama로 실행하면 모델 처리도 같은 컴퓨터에서 이루어집니다.
- 외부 교육 자료 검색에는 아이 이름이나 관찰 원문을 보내지 않습니다.
- 특정 원격 AI를 직접 설정하지 않는 한 GrowWise가 임의로 아동 기록을 외부 모델로 보내지 않습니다.
- 아이를 삭제하면 해당 아이의 현재 로컬 기록과 파생 데이터를 함께 정리합니다.
- 과거에 만든 백업 파일은 별도 파일이므로 필요하면 직접 삭제해야 합니다.

외부 자료는 이용 조건도 함께 확인합니다. 예를 들어 Open Library는 상업 이용 정책과의 충돌을 피하기 위해
**live API를 production discovery에서 호출하지 않는다**는 정책을 유지하며, 별도로 검증된 안전한
오프라인 메타데이터만 사용할 수 있습니다.

자세한 내용은 **[개인정보와 안전](docs/privacy-and-safety.md)**을 참고하세요.

## 교육과정은 어떻게 반영되나요?

GrowWise는 아이의 생년월일 또는 학년과 현재 날짜를 기준으로 적용 교육과정을 선택합니다.

한국 교육과정이 학년별로 순차 적용되는 기간에도 모든 학생에게 같은 개정본을 일괄 적용하지 않습니다. 공식 교육과정 변경이 감지되면 새 고시 후보를 확인하도록 되어 있으며, 검증되지 않은 웹 문서를 곧바로 활동 기준으로 사용하지 않습니다.

사용자는 이 정보를 매번 확인할 필요가 없습니다. 기본 활동 화면에서는 숨겨 두고, 필요할 때만 상세 정보에서 확인할 수 있습니다.

---

## 현재 상태

GrowWise는 현재 **pre-1.0** 단계입니다.

저장소의 주요 기능, Windows/macOS 패키징 경로, 자동 테스트와 보안 검사는 구현되어 있습니다. 다만 일반 사용자용 정식 공개 배포 전에 다음 실제 운영 검증이 남아 있습니다.

- 실제 가정에서의 장기 사용 테스트
- 대표 하드웨어에서 로컬 AI 속도와 품질 측정
- Windows/macOS 정식 코드 서명
- macOS notarization
- 업데이트 서명 키와 실제 업데이트 복구 테스트

현재 GitHub Releases에는 정식 signed installer가 아직 공개되어 있지 않습니다. 개발 빌드와 소스 실행 방법은 **[기술 가이드](docs/technical-guide.md)**에 분리되어 있습니다.
