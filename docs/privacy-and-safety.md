# 개인정보와 안전 원칙

growwise는 아동을 대상으로 하는 도구이며, 이 저장소는 공개(public)다. 따라서
개인정보 보호는 부가 기능이 아니라 설계의 전제다.

## 제품 안전 원칙

- 아이에게 직접 보여주기 전 **부모 또는 교사 검토를 기본값**으로 둔다.
- 아이를 **점수화하거나 낙인찍는 표현**을 피한다.
- 평가보다는 **관찰, 다음 활동, 흥미 변화** 중심으로 기록한다.
- 사진, 음성, 위치, 실명 정보는 **기본 비공개(로컬 전용)**로 둔다.
- 외부 API로 전송되는 데이터는 **최소화**한다.
- 기관용으로 확장할 경우 **개인정보 처리와 보호자 동의 구조**가 핵심이다.

## 데이터 처리 원칙

1. **로컬 우선(local-first)**: 아동 프로필·학습 기록·생성물·음성은 데스크탑 로컬에
   저장하며, 외부 전송을 기본값으로 삼지 않는다.
2. **경계 통제**: 외부 자료 접근은 `adapters/` 계층으로만 한다. 어댑터로 나가는
   요청에는 아동 식별 정보를 포함하지 않는다.
3. **최소 수집**: 자료 생성에 꼭 필요한 정보만 다룬다. 생년·주소·연락처 등은
   시스템 기능에 필요하지 않으므로 다루지 않는다.
4. **검토 게이트**: 생성물은 `review/`(Parent Review Layer)를 거쳐 난이도·민감성·
   개인정보 노출을 점검한 뒤에만 노출한다.

## 모델·저장·전송 프라이버시 (구현 계약)

"로컬=비공개"라는 가정은 동기화·원격모델·내보내기까지 봐야 진짜다([threat-model.md](threat-model.md)).

- **Model Provider egress 계약**: 원격 모델을 켜면 아이의 말·기록이 프롬프트로 나간다.
  따라서 원격 추론도 **"경계 통제" 대상**으로 다룬다 — (a) 기본값은 로컬, (b) 원격은
  **호출당 명시 동의**, (c) 전송 전 **실명·위치 등 식별정보 리댁션**, (d) 무엇이 나가는지
  사용자에게 고지. 원격 모델은 사실상 외부 어댑터다.
- **저장 위치**: 아동 데이터는 **동기화되지 않는 앱 전용 경로**(OS app-data)에 저장한다.
  Documents/바탕화면 등 **OneDrive·iCloud 동기화 폴더에 두지 않는다**(자동 유출 방지).
  선택적 at-rest 암호화를 제공한다.
- **내보내기(export) 리댁션**: Markdown 묶음 내보내기 시 실명·관찰 등을 **리댁션할 수
  있게** 하고, 목적지(공유 폴더/클라우드) 경고를 띄운다.
- **탐방 위치 예외**: 탐방은 집 주변 좌표=식별정보를 쓰므로, 좌표 coarsen 또는 사용자
  입력 장소만 사용하고 **프라이버시 예외로 동의**를 받는다.
- **API 키**: `.env` 평문 대신 OS 키체인/자격증명 저장소 사용을 권장.
- **외부 콘텐츠**: 웹·도서·지도에서 가져온 텍스트는 **데이터로만** 취급(지시로 해석 금지,
  prompt injection 방지).

데이터 보존·삭제(삭제권, ~18년 누적, 백업/복구)는 [threat-model.md](threat-model.md) 참고.

## 저장소(repo) 규칙 — 공개 저장소이므로 필수

이 공개 저장소에는 **실제 아동 데이터를 절대 커밋하지 않는다.**

- 커밋 금지: 실명, 생년월일, 주소/거주지, 사진, 음성 원본, 개인 연락처,
  실제 학습 기록·관찰 메모, 채워진 `child_profile`.
- 저장소에는 **스키마·예시(값 없는 형태)·합성 데이터**만 둔다.
- 실제 데이터 경로(`data/`, `storage/`, `learning_logs/`, `generated/`, `*.db` 등)는
  [`.gitignore`](../.gitignore)로 광범위하게 제외돼 있다.
- 비밀정보(API 키 등)는 `.env`로 두고 저장소에 올리지 않는다. 공유가 필요한 설정은
  값 없는 `*.example` 파일로만 제공한다.

## 향후 과제(기관용)

기관용 단계에서는 다음이 추가로 필요하다.

- 보호자 동의 획득·철회 구조
- 데이터 보관·파기 정책
- 원내 서버 배포 시 접근 통제와 감사 로그
- 관련 아동·개인정보 보호 법령 검토
