# GrowWise 사용자 가이드

GrowWise는 아이의 실제 질문과 경험을 **짧게 기록 → 다음 활동 → 실제 경험 → 결과 기록 → 다시 다음 활동**으로 이어 주는 가족용 데스크톱 앱입니다. 아이 기록은 기본적으로 이 기기에 저장되며, AI를 사용하지 않아도 핵심 기록·검색·자료 관리·백업 기능은 동작합니다. 교육과정·출처·내부 검토 상태 같은 상세 정보는 기본 화면에서 숨기고 필요할 때만 확인하도록 설계되어 있습니다.

## 데스크톱 화면 구조

왼쪽 사이드바에는 다음 9개 제품 작업공간만 노출됩니다.

1. **대시보드**
2. **아이 프로필**
3. **학습 기록**
4. **자료실**
5. **사진첩**
6. **대화하기**
7. **백업 및 복원**
8. **설정**
9. **도움말**

설정과 도움말은 사이드바 하단의 유틸리티 메뉴입니다. 이전의 관찰 기록, 성장 보기, 활동, 자료 찾기, 참고 자료는 독립 사이드바 메뉴가 아니라 관련 상위 작업공간의 탭 또는 하위 기능으로 들어갑니다.

공통 상단바에는 **검색 진입점 → 알림 → 현재 아이 프로필**이 배치됩니다. 검색 단축키는 Ctrl/Cmd + K이며 대화하기 작업공간으로 이동합니다.

## 처음 시작하기

1. **아이 프로필**에서 닉네임과 생년월일을 입력합니다. 첫 아이를 저장하면 바로 자료실의 첫 활동 준비 흐름으로 이어집니다.
2. **자료실**에서 주제를 입력해 활동 자료를 만들고 내용을 확인한 뒤 **이 활동 사용하기**를 누릅니다.
3. 활동이 끝나면 **한 줄 기록**만 남겨도 다음 자료와 추천에 반영됩니다. 더 남기고 싶을 때만 상세 기록을 펼칩니다.
4. 일상의 배움은 **학습 기록**의 학습 기록/관찰 기록 탭에 추가로 남길 수 있습니다.
5. 사진 중심의 활동은 **사진첩**에서 기록하고 필요하면 학습 기록과 연결합니다.
6. 과거 기록을 근거로 질문하거나 검색하려면 **대화하기**를 사용합니다.
7. **백업 및 복원**에서 관리 백업을 만들고 복원/가져오기/내보내기를 수행합니다.
8. 프로필 상세 정보, 앱 상태, AI/개인정보 관련 항목은 **설정**에서 관리합니다.

## 대시보드

현재 아이와 최근 상태를 빠르게 확인하는 시작 화면입니다.

### 표시되는 요약

- 등록된 아이 수
- 최근 학습 기록
- 진행 중인 추천 활동
- 최근 백업 상태
- 최근 활동 기록
- 오늘의 추천 활동 또는 검토할 자료

대시보드는 점수판이 아닙니다. 기록량, 성장 축, 활동 완료율을 성취 점수처럼 표시하지 않습니다.

## 아이 프로필

아이의 기본 정보와 장기 기록 흐름을 한곳에서 봅니다.

### 왼쪽 프로필 카드

- 프로필 사진
- 닉네임
- 생년월일 또는 직접 입력한 월령/학년
- 현재 교육 단계
- 아이 전환
- 관심사
- 최근 학습 목표
- 부모 메모
- 프로필 편집

프로필 편집은 **설정**의 실제 프로필 편집 화면으로 연결됩니다. 아이 추가 · 사진 관리는 별도 관리 동작입니다.

### 오른쪽 탭

#### 학습 기록

선택한 아이의 실제 기록 목록과 상세 내용을 확인합니다.

#### 발달 분석

최근 기록이 어떤 경험 축에 연결됐는지 살펴봅니다. 이 화면은 기록 분포를 보여주는 회고 도구이며 능력, 발달 수준, 또래 순위를 점수화하지 않습니다.

#### 성장 리포트

시간 순서로 쌓인 기록과 반복되는 관심을 확인합니다. Learning Wiki에는 원본 기록에서
이어지는 관심·질문·다음 활동을 근거와 함께 정리합니다. **원본 기록에서 다시 정리**로
파생 맥락을 재생성할 수 있고, AI 보강인지 규칙 기반 정리인지 확인할 수 있습니다.
원본 기록이 기준이며 이 요약은 발달 진단이나 능력 판정이 아닙니다.

## 학습 기록

배움의 결과와 과정, 일상의 관찰을 같은 기록 흐름 안에서 관리합니다.

### 학습 기록 탭

기록 유형 예시:

- 독서 회고
- 일기
- 학교·학원 등 기관 수업
- 자기주도 학습
- 과제
- 기타 학습 기록
- 승인된 학습 자료 사용 결과

기록에는 제목, 날짜, 과목/기관, 학습 내용, 아이 결과물, 흥미, 어려움, 다음 활동, 경험 축, 태그 등을 남길 수 있습니다.

**책과 AI 도움·근거를 더 기록하기(선택)**를 펼치면 함께 읽은 책, 실제로 받은 AI 힌트,
근거 확인 여부, 아이가 자기 말로 다시 설명한 내용을 남길 수 있습니다. 참고 자료에 저장되어
현재 아이가 볼 수 있는 책만 연결합니다. **기록하지 않음**과 **확인하지 않음**은 다르며,
비워 둔 항목을 앱이 임의로 부정적인 평가로 바꾸지 않습니다. 자료 사용 결과의 **더 자세히 기록**에서도
같은 항목을 쓸 수 있고, 저장한 기록·결과의 상세와 관찰 타임라인에서 다시 확인합니다.

중·고 단계에서는 진도, 오답, 회고, 자기설명, 복습 지도/계획을 위한 학습 트래커가 추가로 표시됩니다.

### 관찰 기록 탭

부모가 실제로 본 행동, 질문, 반응, 관심, 어려움을 짧게 남깁니다.

- 자유 관찰 원문
- 경험 축
- 진행 중 활동과 연결
- 관찰 타임라인
- 선택적 AI 보조 태깅/맥락 정리

AI가 꺼져 있거나 실패해도 부모가 입력한 원문은 로컬 정본으로 먼저 저장됩니다.

## 자료실

자료실은 네 개의 탭으로 구성됩니다.

### 활동 자료

아이 맥락과 부모가 선택한 근거를 사용해 실제 활동에 쓸 자료를 만듭니다.

지원 종류:

- 활동 가이드
- 독서 활동
- 영어 카드
- 수학 활동
- 과학 탐구
- 글쓰기 프롬프트
- 탐방 활동

첫 화면은 **문서 캔버스 + 생성 옵션** 구조입니다. 사용자는 먼저 실제 활동에 필요한 내용만 확인합니다.
생성된 자료가 괜찮으면 **이 활동 사용하기**를 한 번 누르면 됩니다.

부모용 상세 교안, 교육과정 연결, 출처·근거는 기본적으로 접혀 있으며 필요할 때만 열어볼 수 있습니다.
내부적으로는 자료가 안전한 상태 전이를 거쳐 사용 가능한 상태가 되지만, 일반 사용자가 초안·검토·승인
단계를 직접 관리할 필요는 없습니다. 직접 편집, 수정 요청, 이전 버전 관리가 필요할 때만
**자료 수정·검토 관리**를 펼칩니다.

접힌 부모용 교안에서 작성 방식, 생성 규칙 버전, 실제 AI 보강에 사용한 모델과 부모 결정
시각도 확인할 수 있습니다. 기본 양식이나 부모 수정본에는 AI 작성 모델을 표시하지 않으며,
자료를 보관해도 기존 부모 결정 시각은 유지됩니다. 이전 자료에 없는 정보는 추정하지 않습니다.

활동이 끝난 뒤 결과 기록의 기본 입력은 **부모 관찰 한 줄**입니다. 아이 답변·산출물, 과정, 질문,
흥미, 어려움, 다음 활동, 사진, 경험 축은 **더 자세히 기록**에서 선택적으로 추가합니다.

인쇄/PDF는 사용 준비가 된 자료를 대상으로 합니다. AI가 없어도 같은 활동 구조의 deterministic
template으로 기본 자료를 만들 수 있습니다.

### 활동 관리

추천 활동과 실제 활동의 lifecycle을 관리합니다.

- 생성됨
- 진행 중
- 완료됨
- 건너뜀
- 결과 기록됨

건너뜀은 실패가 아닙니다. 활동은 부모가 선택하는 후보이며 강제 과제가 아닙니다.

### 참고 자료

부모가 직접 입력했거나 자료 찾기에서 채택한 근거를 관리합니다.

- 책·웹·교육과정·노트·파일성 자료
- 제목·요약·출처·저자·태그
- 아이별/공용 범위
- 수정·삭제
- provenance 확인
- 다른 아이와 원본 공유

외부 검색 결과가 자동으로 참고 자료가 되지는 않습니다.

공유한 원본의 소유자는 연결 패널에서 **연결 해제**로 다른 아이와의 공유만 해제할 수
있습니다. 공유 해제는 원본 자료·사진·관찰을 삭제하지 않습니다.

### 자료 찾기

공개 교육 자원 후보를 찾습니다.

외부 검색에는 아이 이름, 관찰 원문, 부모 메모, 사진을 보내지 않습니다. 일반화된 주제어나 공개적인 학령 조건만 전달합니다. 부모가 참고 자료에 저장을 선택한 결과만 장기 근거 자료에 편입됩니다.

## 사진첩

사진첩은 **갤러리 우선** 구조입니다.

### 기본 화면

- 전체
- 기록 완료
- 검토 필요

필터를 바꿔 사진 기록을 찾고, 카드를 선택하면 상세 패널에서 날짜, 작성 방식, 관찰 기록, 태그, 다음 활동 등을 확인할 수 있습니다.

### 새 사진 기록

새 사진 기록 영역에서:

1. 사진을 선택합니다.
2. 부모 설명 또는 직접 쓴 관찰 기록을 입력합니다.
3. 필요하면 AI 보조를 켭니다.
4. 여러 아이가 함께한 활동이면 공유할 아이를 선택합니다.
5. 초안을 검토하고 확정합니다.

사진 원본은 로컬 managed asset에 저장됩니다. 정확한 GPS 좌표는 기본 기록 데이터로 보존하지 않으며, AI 처리가 실패해도 사진과 부모 기록 자체는 유지됩니다.

사진 AI 처리가 실패했다면 해당 기록을 소유한 아이의 상세 화면에서 **사진 분석 다시 시도**를
선택할 수 있습니다. 다른 아이에게 공유된 사진을 보는 것만으로 소유자의 분석을 다시 실행하지 않습니다.

## 대화하기

대화하기는 세 영역으로 구성됩니다.

1. **왼쪽: 대화 목록** — 새 대화와 이전 대화 세션
2. **가운데: 대화/질문** — 아이의 기록과 저장한 자료를 근거로 검색·후속 질문
3. **오른쪽: 백업 보조 패널** — 현재 기록을 안전하게 보관하기 위한 빠른 백업 동작

이전 대화를 선택하면 실제 후속 질문도 해당 세션을 이어갑니다. AI가 없으면 자연어 생성 보조는 제한되지만 child-scoped lexical 검색과 저장 자료 조회는 유지됩니다.

**선택한 대화 삭제**는 확인 후 대화 세션과 메시지만 삭제합니다. 대화의 근거였던 아이 기록과
자료는 보존됩니다. 이미 만든 과거 백업에 포함된 대화는 별도 snapshot으로 남을 수 있습니다.

## 백업 및 복원

백업은 설정에서 분리된 독립 작업공간입니다.

- 현재 백업 상태 확인
- 관리 백업 생성
- 백업 ZIP 내보내기
- 외부 백업 가져오기
- 선택한 백업 복원
- 백업 이력 확인

복원은 경로, 파일 수, 크기, 링크, manifest 등의 안전성 검증을 통과한 snapshot으로 수행됩니다. 기존 backup ZIP은 과거 시점의 immutable snapshot입니다.

**선택 기록 내보내기**에서는 아이와 시작일·종료일을 골라 원본 Markdown과 필요한 사진·첨부를
ZIP으로 저장합니다. 날짜를 비우면 해당 방향의 제한이 없고, 지정한 날짜는 양 끝을 포함합니다.
아이 프로필과 기록에 연결된 책·자료·사진은 근거 보존을 위해 기간 밖이어도 포함될 수 있습니다.
이 ZIP은 이름·관찰·사진을 그대로 담는 개인정보 파일이며, 전체 백업 복원에는 사용할 수 없습니다.
전체 복원이 목적이면 기존 백업 기능을 사용하세요. 상세 범위와 제한은
[아이·기간별 원본 기록 내보내기](record-export.md)를 참고합니다.

## 설정

설정은 **앱 상태 + 가족 프로필 + 개인정보**를 관리합니다.

### 앱 상태

**앱 업데이트**에서 현재 버전을 확인합니다. 자동 업데이트가 설정된 배포본은 **새 버전 확인**
후 **다운로드·설치…**로 진행하며, 먼저 작성 중인 내용을 저장하고 설치·재시작을 확인합니다.
파일 서명을 확인한 뒤 설치하며 다운로드나 검증 실패 시 설치하지 않습니다. 진행 중 확인창은
새 입력을 막고, 실패하면 오류와 함께 닫힙니다. 현재 검증 빌드는 신뢰 키가 설정되기 전까지
자동 업데이트 미설정 상태를 표시합니다. 아이 기록은 업데이트 서버로 보내지 않습니다.

- Core 연결 상태
- 현재 아이
- 등록된 아이 수
- AI 보조 기능 사용 가능 상태

### 로컬 AI 모델 관리

기록·자료 만들기, 사진 이해, 검색 보강 중 용도를 선택해 해당 로컬 Ollama에 설치된 모델을
확인할 수 있습니다. **이 모델 사용**은 지원 용도를 확인한 뒤 선택을 저장하고 AI 연결을
다시 시작합니다. 진행 중 AI 작업은 재시도될 수 있으므로 모델 변경은 작업이 끝난 뒤 권장합니다.
다른 용도의 모델 선택은 자동으로 바꾸지 않습니다.

**필요한 모델 준비**는 현재 설정된 누락 모델을 내려받습니다. **삭제…**는 별도 확인 후 선택한
모델만 Ollama에서 삭제하며, 같은 Ollama를 사용하는 다른 앱에도 영향을 줄 수 있습니다.
아이 기록·사진·자료는 삭제하지 않고 모델을 다시 준비하기 전까지 해당 AI 기능만 제한됩니다.
설치 정보의 digest는 Ollama 메타데이터이며 디스크 파일을 새로 검사한 결과가 아닙니다.

### 개인 API 키

도서관 정보나루, Google Books, 국립중앙도서관 ISBN, 한국어기초사전, 공공데이터포털을 직접
사용할 때 **설정 → 개인 API 키**에 본인 키를 입력합니다. 고급 원격 호환 AI 키도 같은 곳에서
관리하지만 키 저장만으로 원격 모델 사용에 동의하거나 공급자·주소를 바꾸지는 않습니다.

**키 저장 · 적용**은 macOS Keychain 또는 Windows Credential Manager에 저장한 뒤 Core를
다시 시작해 적용합니다. 입력란은 비워지고 저장된 키 원문을 다시 보여주지 않습니다.
표시 상태는 저장됨·환경변수에서 제공됨·사용 해제됨·등록 안 됨입니다. 진행 중 AI 작업이
재시도될 수 있으므로 작업이 끝난 뒤 설정을 바꾸는 편이 좋습니다.

**실제 연결 확인**은 고정된 공개 검색 입력과 새 임시 캐시로 응답을 확인합니다. 아이 이름·관찰·
사진·현재 위치를 테스트에 사용하지 않습니다. 빈 검색 결과는 응답을 받았다는 뜻이며 키의 권한이
정상이라고 확정하지 않습니다. 원격 호환 AI의 연결 확인은 설정된 공급자에 고정 테스트 문장만 보냅니다.

**키 사용 해제…**는 확인 후 이 앱의 키 사용을 중단합니다. 환경변수에 같은 서비스의 키가 남아
있어도 자동으로 다시 사용하지 않습니다. 다시 사용하려면 키를 새로 등록합니다. 발급 서비스에서
키 자체를 폐기하는 작업은 별도로 해야 합니다.

API 키는 가족 공통 설정이며 아이 삭제로 함께 폐기하지 않습니다. 키는 백업 ZIP에 포함되지
않으므로 다른 컴퓨터에서는 다시 등록해야 합니다. OS 보안 저장소 접근이 실패하면 키를 평문으로
대체 저장하지 않고 키가 필요한 선택 기능을 제한하며 로컬 기록 기능은 계속 동작합니다.
Linux 개발 환경에서는 앱 내 OS 키 저장을 지원하지 않으며 고급 환경변수 설정을 사용합니다.

### 기록 저장 위치

**저장 폴더 변경**에서 현재 위치와 겹치지 않는 빈 폴더를 선택합니다. 확인 후 Core의 쓰기를
멈추고 기록·사진·대화·백업을 함께 복사·검증한 뒤 새 위치로 연결하고 화면을 다시 엽니다.
이전 폴더의 사본은 복구용으로 남습니다. 이전 폴더에도 개인정보가 남으므로 필요가 없어졌을 때
직접 정리해야 하며, 이후 아이 삭제는 현재 저장 위치만 정리합니다.
OS 보안 저장소의 API 키와 Ollama 모델 파일은 이 데이터 폴더와 별도로 관리됩니다.

### 개인정보와 삭제

아이 삭제는 프로필 한 건만 지우는 작업이 아닙니다. 해당 아이의 live Markdown 기록, projection, RAG, 대화, background job, 사진 asset, 링크 등 child-scoped live data를 함께 정리합니다.

과거 backup ZIP은 자동 수정하지 않으므로 완전 폐기가 필요하면 해당 백업도 별도로 관리해야 합니다.

## 도움말

도움말에는 시작하기, 기록/자료/사진/대화 사용법, Local-first 데이터 원칙, 백업/복원과 삭제, AI 역할, 단축키, 버전/라이선스/문제 해결 안내를 모아 둡니다.

## AI 보조 기능

GrowWise의 기본 원칙은 **로컬 정본이 먼저, AI는 나중**입니다.

- AI 초기화 실패가 기록 저장 실패로 바뀌지 않습니다.
- background AI 작업이 실패해도 이미 저장된 원본은 유지됩니다.
- 학습 자료 AI 보강이 실패해도 기본 초안은 유지됩니다.
- AI가 꺼져 있어도 기록, 참고 자료, lexical 검색, deterministic 자료 생성, 백업/복원은 계속 사용할 수 있습니다.

## 문제가 생겼을 때

1. 저장 버튼을 반복해서 누르기보다 완료/오류 상태를 먼저 확인합니다.
2. timeout 뒤 동일 요청이 재시도되더라도 GrowWise는 idempotency key와 reserved ID를 사용해 중복 생성을 방지합니다.
3. 문제가 반복되면 **설정**의 앱 상태를 확인합니다.
4. 데이터 작업 전에는 **백업 및 복원**에서 관리 백업을 만들어 두는 것이 좋습니다.
5. 제품 사용법 자체가 궁금하면 **도움말**을 확인합니다.
