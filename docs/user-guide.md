# GrowWise 사용자 가이드

GrowWise는 기록만 남기는 일기장이 아니라 **기록 → 연결 → 자료 발견 → 자료 생성 → 부모 검토 → 회고**를 한 곳에서 관리하는 개인용 교육 운영 도구다. AI는 이 흐름을 보조하지만 필수 조건이 아니다.

## 처음 시작하기

1. **홈**에서 아이 프로필을 만든다.
2. 평소에는 **관찰** 또는 **사진 기록**에서 실제 경험을 남긴다.
3. **활동**에서 다음에 해볼 활동을 고르거나 진행 상태를 기록한다.
4. **발견**에서 현재 관심사·최근 기록과 연결되는 공개 교육 자원, 도서, 교육과정 근거를 찾는다.
5. 필요한 후보만 **라이브러리**에 저장한다.
6. **자료**에서 저장한 근거와 아이 맥락을 바탕으로 활동지·독서활동·탐구자료 등을 만든다.
7. 생성물은 부모가 검토하고 승인한 뒤 사용하거나 인쇄한다.
8. **검색**과 **성장**에서 장기 기록을 다시 살펴본다.
9. **설정**에서 백업·복원·삭제 등 데이터 수명주기를 관리한다.

---

## 홈

### 무엇을 하는 화면인가

아이별 GrowWise 맥락의 시작점이다. 아이 프로필을 만들고 현재 선택된 아이를 바꾼다.

### 할 수 있는 일

- 아이 프로필 생성
- 연령/단계와 관심사 입력
- 여러 아이 사이 전환
- 현재 선택된 아이의 기록·자료 컨텍스트 진입
- GrowWise 기능 상태 확인

### 알아둘 점

아이를 전환하면 관찰, 활동, 자료, 검색 등 child-scoped 화면도 그 아이의 범위로 바뀐다. GrowWise는 한 아이의 비동기 요청 결과가 다른 아이 화면에 섞이지 않도록 child scope를 분리한다.

---

## 관찰

### 무엇을 하는 화면인가

부모가 실제로 본 행동, 질문, 반응, 관심, 어려움 등을 짧게 남기는 핵심 기록 화면이다.

### 할 수 있는 일

- 자유로운 관찰 문장 저장
- 경험 축을 직접 선택해 함께 기록
- 진행 중인 활동과 후속 관찰 연결
- 저장된 관찰 타임라인 확인
- 필요할 때 AI 보조 태깅/관심사/다음 활동 힌트 사용

### AI가 없으면

부모가 입력한 원문 그대로 저장된다. 경험 축도 직접 선택할 수 있으며 검색·타임라인·성장 지도는 계속 동작한다. AI 보강 실패 때문에 관찰 저장 자체가 실패하지 않는다.

---

## 사진 기록

### 무엇을 하는 화면인가

아이와 함께한 활동 사진을 **사진 일기**처럼 보존하고, 원하면 로컬 Vision LLM이 기록 초안 작성을 보조하는 화면이다.

### 기본 사용법

1. 기본 아이를 선택한다.
2. 사진을 고른다.
3. 부모 설명 또는 직접 쓴 기록을 입력한다.
4. AI 보조를 원하지 않으면 끈다.
5. 여러 아이가 함께한 활동이면 `같이 연결할 아이`를 선택한다.
6. 초안을 만든다.
7. 부모가 내용을 직접 확인·수정한다.
8. `관찰 기록으로 저장`해 확정한다.

### AI가 없거나 느리면

AI를 끄면 사진과 부모 텍스트만으로 즉시 편집 가능한 초안이 만들어진다. AI를 켰지만 모델이 느린 경우에는 사진을 먼저 안전하게 저장하고 캡션·초안 생성을 durable background job으로 처리한다. 다른 화면을 사용해도 작업은 계속된다.

AI 처리가 반복 실패해도 사진 기록 자체를 실패시키지 않고 직접 기록 가능한 초안으로 전환한다.

### 사진 개인정보

- 원본 사진은 GrowWise 로컬 관리 폴더에 저장한다.
- DB에는 사진 바이너리 대신 경로·hash·MIME·메타데이터 관계를 저장한다.
- 정확한 GPS 좌표는 사진 기록의 기본 데이터로 보존하지 않는다.
- 사진 원본은 기본적으로 로컬 Vision provider에만 전달한다.
- 아이 전체 삭제 시 live 사진 asset도 함께 삭제한다.
- 기존 backup ZIP에는 과거 사진이 남아 있을 수 있으므로 백업은 별도 snapshot으로 관리한다.

## 성장

### 무엇을 하는 화면인가

아이를 점수화하지 않고, 최근 기록에 어떤 경험 축이 나타났는지 장기 맥락으로 살펴보는 화면이다.

### 할 수 있는 일

- 최근 관찰 수 확인
- 신체·표현·탐구·사회·읽기·말하기·쓰기·수학 등 경험 축 보기
- 기록이 특정 축에만 집중됐는지 확인
- 최근 기록의 다양성을 다음 활동을 생각하는 참고자료로 사용

### 해석 원칙

기록이 적거나 특정 축이 비어 있어도 실패나 결손을 뜻하지 않는다. GrowWise 성장 지도는 진단·등수·또래 비교가 아니다.

---

## 활동

### 무엇을 하는 화면인가

부모가 해볼 활동을 선택하고 `선택 → 진행 → 마침 → 후속 관찰` 흐름을 관리한다.

### 할 수 있는 일

- 아이 맥락에 맞는 활동 후보 확인
- 후보를 실제 활동으로 저장
- 시작·완료·건너뜀·다시 시작 상태 관리
- 활동에 연결된 후속 관찰 확인
- `다른 아이와 활동 연결`로 하나의 일정/활동을 여러 아이 문맥에서 공유

### 원칙

활동 추천은 과제가 아니라 선택 가능한 초대다. 완료와 건너뜀은 모두 정상적인 결과다. 여러 아이가 함께한 활동은 문서를 복제하지 않고 `child_scope` 링크로 공유한다.

---

## 검색

### 무엇을 하는 화면인가

오래 쌓인 관찰·활동·자료에서 필요한 맥락을 다시 찾는 화면이다.

### 할 수 있는 일

- 자연어로 아이 기록 검색
- 저장 자료와 관찰 기록을 함께 검색
- 검색 결과를 근거로 후속 질문
- 대화 세션 보존

### RAG 시간 계층

검색은 관련성을 먼저 확인한 뒤 시간 맥락을 다음 순서로 확장한다.

1. 현재 월
2. 같은 연도의 이전 기록
3. 더 오래된 아카이브

최근 기록만 강제로 보여주는 것이 아니라, 관련 있는 현재 맥락을 우선 채운 뒤 근거가 부족할 때 장기 이력으로 확장한다.

### AI가 없으면

child-scoped lexical 검색과 자료 조회는 그대로 동작한다. LLM 질의 재작성·요약·grounded synthesis만 빠진다.

---

## 발견

### 무엇을 하는 화면인가

**GrowWise와 외부 교육 자원을 연결하는 화면**이다. 아이의 관심사와 최근 기록에서 일반 검색어만 로컬로 추출해 공개 교육 자원을 탐색한다.

### 기본 사용법

1. 아이를 선택한다.
2. 특정 주제가 있으면 검색어를 적는다. 비워두면 아이의 관심사, 학습목표, 최근 태그·관심사·활동 제목에서 일반 키워드를 로컬로 고른다.
3. `교육 자료 찾기`를 누른다.
4. 도서·공식 교육과정 등 후보와 출처/이용조건을 확인한다.
5. 실제로 쓰고 싶은 후보만 `라이브러리에 저장`한다.
6. 저장한 자료는 검색 근거가 되고 **자료** 화면에서 생성 근거로 선택할 수 있다.

### 현재 연결되는 소스

- **공식 한국 교육과정 카탈로그**: 앱에 메타데이터를 번들해 네트워크 없이도 공식 출처 링크를 제공한다.
- **공공 교육과정 endpoint**: `GROWWISE_CURRICULUM_ENDPOINT`가 설정된 경우 추가 조회한다.
- **도서관 정보나루**: `GROWWISE_DATA4LIBRARY_API_KEY`가 설정된 경우 관심 주제의 도서 후보를 찾는다.
- **OpenStreetMap Overpass**: 부모가 명시적으로 위치 좌표를 제공한 API 요청에서 주변 도서관·박물관·문화시설 탐방 후보를 찾을 수 있다. 사진 GPS나 아이 데이터에서 위치를 자동 추론하지 않는다.

### 외부로 보내지 않는 것

- child ID
- 아이 이름/닉네임
- 관찰 원문
- 부모 메모
- 사진

외부 adapter에는 `동물`, `우주`, `측정` 같은 일반 검색어와 공개적인 학령 단계/위치 조건만 전달한다.

### 결과는 자동 채택되지 않는다

외부 검색 결과는 임시 후보일 뿐이다. 부모가 저장을 선택해야만 `ResourceRecord`가 되고 RAG에 들어간다. provenance, attribution, license note도 함께 보존한다.

---

## 라이브러리

### 무엇을 하는 화면인가

부모가 직접 입력했거나 **발견** 화면에서 채택한 근거 자료를 관리한다.

### 할 수 있는 일

- 책·웹·교육과정·노트·파일성 자료 저장
- 제목·요약·출처·저자·태그 관리
- 아이별 자료 또는 공용 자료 관리
- 자료 수정/삭제
- provenance 확인
- 저장과 동시에 검색/RAG 근거로 편입
- 자료 상세의 `다른 아이와 자료 연결`로 같은 원본을 형제·자매 문맥에 공유

외부 검색 결과를 무조건 쌓지 않고 실제로 사용할 자료만 라이브러리로 승격시키는 것이 권장 흐름이다.

---

## 자료

### 무엇을 하는 화면인가

아이 맥락과 부모가 선택한 근거를 사용해 실제 교육 활동에 쓸 자료를 만드는 화면이다.

### 만들 수 있는 자료

- 활동 가이드
- 독서 활동
- 영어 카드
- 수학 활동
- 과학 탐구
- 글쓰기 프롬프트
- 탐방 활동

### 기본 사용법

1. 자료 종류를 선택한다.
2. 주제와 목표를 입력한다.
3. 라이브러리에서 근거로 사용할 자료를 선택한다.
4. 자료를 생성한다.
5. 부모가 내용을 검토한다.
6. 승인, 수정 요청, 직접 편집 중 하나를 선택한다.
7. 승인된 자료만 실제 사용/인쇄 대상으로 취급한다.
8. 함께 사용할 아이가 있으면 `다른 아이와 생성 자료 연결`로 같은 생성물을 공유한다.

### AI가 없으면

종류별 deterministic template을 사용해 자료를 만든다. AI가 있으면 문장 구성과 개인화를 보강하지만 source refs, 안전 가드, Parent Review 원칙은 동일하다.

---

## 설정

### 무엇을 하는 화면인가

GrowWise의 로컬 데이터와 운영 상태를 관리한다.

### 할 수 있는 일

- Core/AI 기능 상태 확인
- 관리 백업 생성
- backup ZIP 내보내기/가져오기
- 백업 복원
- 아이별 live data 영구 삭제

아이 삭제는 프로필만 지우는 것이 아니라 Markdown 정본, projection, RAG, 대화, background job, idempotency, checkpoint, 사진 asset, entity link 등 해당 아이의 live 데이터를 함께 정리한다.

# 대표 사용 시나리오

## 1. LLM 없이 사진 일기 쓰기

`사진 기록 → 사진 선택 → AI 보조 끄기 → 부모가 글 작성 → 검토 → 관찰 기록으로 저장`

로컬 모델이 설치되지 않아도 이 흐름은 완전하게 동작한다.

## 2. 기록에서 교육 자료 발견하기

`관찰 누적 → 발견 → 현재 맥락으로 찾기 → 도서/교육과정 후보 확인 → 라이브러리에 저장 → 자료 생성 → Parent Review`

이 흐름이 GrowWise를 단순 일기장이 아니라 교육 운영 도구로 만든다.

## 3. 형제·자매가 함께한 활동 기록하기

`사진 기록 → 기본 아이 선택 → 같이 연결할 아이 선택 → 원본 한 번만 생성 → child_scope 링크 → 각 아이 문맥에서 동일 원본 참조`

활동 화면, 라이브러리 상세, 생성 자료 카드에서도 같은 방식으로 `다른 아이와 연결`을 추가할 수 있다. 같은 사진·활동·근거·생성물을 아이마다 복제하지 않는다. EntityLink가 Obsidian backlink처럼 문서 간 관계를 보존하며, 원본 삭제 또는 아이 삭제 시 dangling link가 남지 않도록 정리한다.

## 4. 오래된 기록 다시 찾기

`검색 → 질문 입력 → 현재 월 근거 우선 → 현재 연도 → 장기 아카이브 확장 → 출처 확인`

LLM이 없으면 검색 결과를 직접 보고, LLM이 있으면 같은 근거를 바탕으로 요약·후속 질문을 사용할 수 있다.

# 외부 API 설정

외부 API는 모두 선택 기능이다. 설정하지 않아도 로컬 기록·검색·자료 생성은 계속 동작한다.

```bash
# 도서관 정보나루
GROWWISE_DATA4LIBRARY_API_KEY=...

# 선택적 공공 교육과정 endpoint
GROWWISE_CURRICULUM_ENDPOINT=https://example.org/curriculum/search
```

> 실제 API 키를 저장소 `.env`, README, issue, 로그에 커밋하지 않는다. 배포판에서는 장기적으로 OS credential store를 사용하는 설정 UX를 제공하는 것이 목표다.

OpenStreetMap Overpass와 번들 공식 교육과정 카탈로그는 별도 키가 필요하지 않는다.

# GrowWise의 AI 원칙

**LLM-enhanced, not LLM-dependent.**

- 부모 입력과 원본 기록이 항상 우선한다.
- AI 결과는 해석/분류/초안/검색 보조다.
- AI 장애가 기록 저장·검색·백업 같은 핵심 기능 장애로 전파되지 않는다.
- 생성물은 Parent Review를 거친다.
- 사진 분석은 가능한 로컬에서 실행한다.
- 외부 공개자료 API에는 아이 식별정보를 보내지 않는다.
