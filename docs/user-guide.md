# GrowWise 사용자 가이드

GrowWise는 아이의 경험과 배움을 **기록 → 연결 → 자료 찾기 → 학습 자료 만들기 → 부모 검토 → 회고** 흐름으로 관리하는 로컬 우선 교육 도구입니다. AI는 선택적인 보조 기능이며, AI를 사용하지 않아도 핵심 기록·검색·자료 관리 기능은 동작합니다.

## 화면 구성

데스크톱에서는 왼쪽 사이드바를 기준으로 이동합니다. 메뉴는 기능 이름을 한 줄로 늘어놓지 않고 목적별로 묶었습니다.

- **홈**
- **기록**
  - 관찰 기록
  - 사진 기록
  - 학습 기록
- **성장과 활동**
  - 성장
  - 활동
- **찾기와 자료**
  - 기록 검색
  - 자료 찾기
  - 참고 자료
  - 학습 자료
- **설정**

화면 폭이 좁아지면 같은 그룹 구조를 유지하면서 상단 영역으로 배치됩니다. 현재 선택한 메뉴는 별도로 표시됩니다.

## 처음 시작하기

1. **홈**에서 아이 프로필을 만듭니다.
2. 아이를 선택합니다. 선택한 아이는 다른 메뉴에서도 유지됩니다.
3. 실제 경험은 **관찰 기록**, **사진 기록**, **학습 기록** 중 상황에 맞는 곳에 남깁니다.
4. 다음에 해볼 활동은 **활동**에서 선택하거나 진행 상태를 기록합니다.
5. 장기 흐름은 **성장**에서 확인합니다. 성장 화면은 점수나 등수를 매기지 않습니다.
6. 과거 기록은 **기록 검색**에서 다시 찾습니다.
7. 공개 교육 자원이나 도서 후보는 **자료 찾기**에서 탐색합니다.
8. 실제로 사용할 근거만 **참고 자료**에 저장합니다.
9. 저장한 근거와 아이 맥락을 바탕으로 **학습 자료**에서 활동지·독서 활동·탐구 자료 등을 만듭니다.
10. 생성된 자료는 부모가 직접 검토한 뒤 승인하거나 수정합니다.
11. 백업·복원·삭제·AI 보조 상태는 **설정**에서 관리합니다.

---

## 홈

현재 선택된 아이와 최근 상태를 한눈에 보고 다음 화면으로 이동하는 시작점입니다.

### 할 수 있는 일

- 아이 프로필 생성
- 여러 아이 사이 전환
- 현재 아이의 최근 기록과 자료 상태 확인
- 관찰 기록, 활동, 학습 자료, 참고 자료 등 주요 작업으로 빠르게 이동

홈의 바로가기는 과제를 추천하거나 완료를 요구하는 기능이 아닙니다. 필요한 작업으로 빠르게 이동하기 위한 진입점입니다.

## 기록

### 관찰 기록

부모가 실제로 본 행동, 질문, 반응, 관심, 어려움 등을 짧게 남기는 기본 기록 화면입니다.

- 자유로운 관찰 문장 저장
- 경험 축 직접 선택
- 진행 중인 활동과 후속 관찰 연결
- 저장된 관찰 타임라인 확인
- 선택적으로 AI 보조 태깅·관심사·다음 활동 힌트 사용

AI가 꺼져 있거나 일시적으로 사용할 수 없어도 부모가 입력한 원문은 먼저 저장됩니다.

### 사진 기록

활동 사진과 부모 설명을 함께 보존하는 사진 일기형 화면입니다.

1. 아이를 선택합니다.
2. 사진을 고릅니다.
3. 부모 설명 또는 직접 쓴 기록을 입력합니다.
4. 필요하면 AI 보조를 켭니다.
5. 여러 아이가 함께한 활동이면 같이 연결할 아이를 선택합니다.
6. 초안을 확인하고 수정합니다.
7. 관찰 기록으로 확정합니다.

사진 원본은 로컬 관리 영역에 저장됩니다. 정확한 GPS 좌표는 기본 기록 데이터로 보존하지 않으며, AI 처리가 실패해도 사진과 부모 기록 자체는 유지됩니다.

### 학습 기록

관찰 외에 학습 과정 자체를 남길 때 사용합니다.

- 독서 회고
- 일기
- 기관 수업
- 자기주도 학습
- 과제
- 학습 자료 사용 결과

결과뿐 아니라 아이가 어떤 방식으로 생각하고 해결했는지 과정 중심으로 남기는 것이 권장됩니다.

## 성장과 활동

### 성장

최근 기록에 어떤 경험 축이 나타났는지 장기 맥락으로 살펴봅니다.

- 최근 기록 수 확인
- 신체·표현·탐구·사회·읽기·말하기·쓰기·수학 등 경험 축 확인
- 기록이 특정 영역에만 몰려 있는지 확인
- 다음 활동을 생각할 때 참고

기록이 적거나 특정 축이 비어 있어도 실패나 결손을 뜻하지 않습니다. GrowWise는 진단·등수·또래 비교를 제공하지 않습니다.

### 활동

부모가 해볼 활동을 고르고 **선택 → 진행 → 마침 → 후속 관찰** 흐름을 관리합니다.

- 활동 후보 확인
- 실제 활동으로 저장
- 시작·완료·건너뜀·다시 시작 상태 관리
- 활동과 후속 관찰 연결
- 여러 아이가 함께한 활동 공유

활동은 과제가 아니라 선택 가능한 후보입니다. 완료와 건너뜀 모두 정상적인 결과입니다.

---

## 찾기와 자료

### 기록 검색

오래 쌓인 관찰·활동·참고 자료에서 필요한 맥락을 다시 찾습니다.

- 자연어로 아이 기록 검색
- 관찰 기록과 저장된 참고 자료 함께 검색
- 근거를 확인하면서 후속 질문
- 대화 세션 보존

AI가 없으면 아이 범위의 텍스트 검색과 자료 조회는 그대로 동작합니다. AI 질의 재작성이나 요약 같은 보조 기능만 빠집니다.

### 자료 찾기

GrowWise와 외부의 공개 교육 자원을 연결하는 화면입니다.

1. 아이를 선택합니다.
2. 직접 검색어를 입력하거나 최근 기록에서 일반 검색어를 구성합니다.
3. 교육 자료 후보를 확인합니다.
4. 출처와 이용 조건을 확인합니다.
5. 실제로 사용할 후보만 **참고 자료에 저장**합니다.

외부 검색에는 아이 이름, 관찰 원문, 부모 메모, 사진을 보내지 않습니다. `동물`, `우주`, `측정` 같은 일반 주제어나 공개적인 학령 조건만 사용합니다.

### 참고 자료

부모가 직접 입력했거나 자료 찾기에서 채택한 근거 자료를 관리합니다.

- 책·웹·교육과정·노트·파일성 자료 저장
- 제목·요약·출처·저자·태그 관리
- 아이별 자료 또는 공용 자료 관리
- 수정·삭제
- 출처 세부 정보 확인
- 다른 아이와 동일 원본 공유

외부 검색 결과가 자동으로 참고 자료가 되지는 않습니다. 부모가 저장을 선택한 항목만 GrowWise의 근거 자료로 들어갑니다.

### 학습 자료

아이 맥락과 부모가 선택한 근거를 사용해 실제 활동에 쓸 자료를 만듭니다.

만들 수 있는 예:

- 활동 가이드
- 독서 활동
- 영어 카드
- 수학 활동
- 과학 탐구
- 글쓰기 프롬프트
- 탐방 활동

기본 흐름은 **초안 생성 → 부모 검토 → 승인 또는 수정 → 사용 결과 기록**입니다. AI가 없어도 deterministic template으로 기본 초안을 만들 수 있습니다. AI는 문장 구성과 개인화를 보강하지만 저장과 검토 흐름의 필수 조건이 아닙니다.

## 설정

GrowWise의 로컬 데이터와 운영 상태를 관리합니다.

- 앱 상태 확인
- 선택적인 AI 보조 기능 상태 확인
- 관리 백업 생성
- 백업 ZIP 내보내기·가져오기
- 백업 복원
- 아이별 live data 영구 삭제
- 필요할 때 고급 진단 정보 확인

기술적인 Core/provider/runtime 정보는 일반 사용 흐름에서 요구하지 않으며, 필요한 경우에만 고급 진단 정보에서 확인합니다.

## 백업과 복원

- 백업은 GrowWise 관리 영역의 snapshot입니다.
- 외부 백업을 가져올 때는 현재 상태를 먼저 안전 백업합니다.
- 복원 파일은 경로, 파일 수, 크기, 링크, manifest 등 안전성 검증을 거칩니다.
- 복원 실패 시 기존 live data를 가능한 한 보존합니다.

## 아이 데이터 삭제

아이 삭제는 프로필 한 건만 지우는 작업이 아닙니다. 해당 아이와 연결된 live Markdown 기록, 검색 projection, RAG, 대화, background job, 사진 asset, 링크 등 관련 데이터를 함께 정리합니다.

백업 ZIP은 과거 시점의 독립 snapshot이므로 이미 만들어 둔 백업 안의 데이터까지 자동으로 삭제되지는 않습니다. 필요한 경우 해당 백업도 별도로 관리해야 합니다.

## AI 보조 기능

GrowWise의 기본 원칙은 **로컬 정본이 먼저, AI는 나중**입니다.

- AI 초기화 실패가 기록 저장 실패로 바뀌지 않습니다.
- background AI 작업이 실패해도 이미 저장된 원본은 유지됩니다.
- 학습 자료의 AI 보강이 실패해도 기본 초안은 유지됩니다.
- AI가 꺼져 있어도 기록, 참고 자료, 검색의 기본 기능을 계속 사용할 수 있습니다.

## 문제가 생겼을 때

1. 저장 버튼을 연속으로 여러 번 누르기보다 화면의 완료·오류 상태를 먼저 확인합니다.
2. 일시적인 연결 timeout이 발생한 생성 요청은 GrowWise가 동일 작업 키로 안전하게 재시도합니다.
3. 문제가 반복되면 **설정 → 고급 진단 정보**를 확인합니다.
4. 데이터 작업 전에는 관리 백업을 만들어 두는 것이 좋습니다.
