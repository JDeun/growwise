# Python 런타임 보안 기준 변경 — 2026-11-03

이 기록은 Python 3.12.13을 고정했던 패키지의 보안 적합성을 재검토한 결과다.
공식 보안 릴리스와 실제 호출 경로를 확인했다. 악성 입력 공격을 실행하거나,
새 Python 3.12.16 설치 파일의 빌드·실행 성공을 확인한 기록은 아니다.
구조화된 근거와 소스 해시는 [JSON](python-runtime-security-20261103.json)에 보존한다.

## 공식 수정과 앱의 영향 경로

| 수정 | 실제 경로와 경계 |
| --- | --- |
| Python 3.12.15, CVE-2026-15310: ZIP bzip2/LZMA 해제 중 메모리 고갈 | `backup/service.py:295`에서 부모가 선택한 복원 ZIP을 열고, 메타데이터 검사 후 `:300`에서 해제한다. `:543` 검사는 크기·경로 등을 제한하지만 압축 방식을 제한하지 않는다. `:449`의 제한된 manifest 읽기도 해제기의 내부 할당보다 먼저 적용되는 보호가 아니다. |
| Python 3.12.16, CVE-2026-115557: 유출된 eMudhra 중간 인증서 키 차단 | 사용자가 원격 모델을 명시적으로 설정하면 `model/openai_compatible.py:116–125`에서 Bearer 헤더와 요청을 HTTPS로 전송한다. 공개 자료는 `adapters/http.py:143–150`을 사용한다. 같은 출처 리디렉션 검사와 응답 크기 제한은 인증서 신뢰 문제를 해결하지 않는다. 로컬 Ollama만 사용하는 경로에 동일한 원격 TLS 노출을 주장하지 않는다. |
| Python 3.12.16, CVE-2026-77214 / CVE-2026-102633: 포함 Expat 2.9.0 갱신 | 선택적으로 사용하는 외부 XML 응답을 `adapters/krdict.py:96`, `adapters/heritage_palace.py:118`에서 `ElementTree.fromstring`으로 읽는다. HTTPS·본문 크기 제한이 있어도 XML 파서 자체의 수정 여부를 대신하지 못한다. 해당 공격을 이 앱에서 재현했다는 의미는 아니다. |

근거는 [Python 3.12.15 보안 릴리스](https://www.python.org/downloads/release/python-31215/),
[ZIP 해제 수정 원인](https://github.com/python/cpython/issues/156002),
[Python 3.12.16 보안 릴리스](https://www.python.org/downloads/release/python-31216/),
[SSL 인증서 차단 논의](https://github.com/python/cpython/issues/160040),
[Expat 갱신](https://github.com/python/cpython/issues/158876)이다.
ZIP 수정 원문은 해제된 데이터가 요청 길이와 `file_size`에 맞춰 잘리기 **전에**
큰 할당이 일어났음을 명시한다. 따라서 기존 애플리케이션 제한만으로 이 런타임 결함을
해결했다고 판단하지 않았다. 별도의 자체 해제기 우회는 추가하지 않는다.

## 적용·확인한 범위

- `pyproject.toml`과 `uv.lock`의 최소 버전을 `>=3.12.16`으로 변경했다.
- 잠금 파일의 108개 패키지 전체 객체를 이전 HEAD와 비교해 동일함을 확인했다.
  의존성 버전·아티팩트를 다시 선택하지 않았다.
- 격리된 uv 0.12.13으로 잠금 파일을 생성하고 오프라인 `uv lock --check`를 통과했다.
  기존 호스트 Python 설정이나 공용 가상환경은 변경하지 않았다.
- README에 최소 버전과 사용 중인 Python 계열의 최신 보안 패치 적용을 안내했다.
  이 하한이 모든 더 높은 minor 버전의 오래된 패치까지 안전하게 만든다는 주장은 하지 않는다.

## 이전 근거와 남은 검증

[이전 패키지 검증](package-validation-20261103.md)은 Python 3.12.13 / 배포판 20260623으로
실제로 관찰한 서명·라이선스·Core 동작 기록으로 남긴다. 기록을 삭제하거나 성공 여부를
바꾸지 않는다. 다만 **출시용 런타임 보안 적합성의 근거로는 대체된다**.

이 문서를 기록한 시점에는 Python 3.12.16 배포판의 정확한 출처·포함 네이티브 라이선스 갱신과
새 Windows/macOS 패키지·실행 검증이 진행 중이다. 새 런타임의 패키징 CI, 설치 파일,
실제 포함 Core 검증은 **아직 통과로 기록하지 않는다**. 후속 관찰은 별도 근거로 추가한다.

개인정보 검토: 공개 보안 문서, 저장소의 코드 경로·해시와 집계만 포함한다.
실제 가정 데이터·자격증명·사용자 SID·개인 기기 경로는 포함하지 않는다.
