## 해석 경계

- 내려받은 설치 파일을 macOS에서 실행하거나 Windows에 설치하지 않았다.
- PE의 `0x14c`는 NSIS 실행 스텁의 형식이다. 내부 앱을 추출해 아키텍처를 다시 검증한 것은 아니다.
- PE 인증서 테이블 오프셋과 크기는 모두 0이다. Authenticode 서명이나 정식 배포 인증을 주장하지 않는다.
  NSIS 형식 표식이 있다는 확인은 디지털 서명 검증이 아니다.
- 실제 Rust WebView 화면에서 전체 사용자 흐름을 실행하는 검증은 별도 작업이다.
- [앞선 런타임 보안 검토](python-runtime-security-20261103.md)의 당시 미완료 상태는 그대로 보존한다.
  이 새 기록이 Python 3.12.16 **Windows 패키지 경로**의 후속 관찰이다.
