# Pedagogy investigation

현재 근거: source:GW-PEDAGOGY-DESIGN, source:GW-PEDAGOGY-CODE, source:GW-PR-181,
source:GW-TUTORMOMENTS-CANDIDATE.

[교육 원칙](../pedagogy.md)은 부모 중심, 최소 기록, 비진단, 자기 설명과 검증을 우선한다.
이는 제품 설계 기준이며 특정 아이의 학습 효과를 입증하는 실험 결과가 아니다.

[단계별 자료 회귀](../../tests/test_material_editorial_quality.py)는 infant/preschool/elementary/
secondary 과제의 발달 단계 구분을 검증한다. [콘텐츠 QA](../material-content-qa.md)는
출력 구조와 현장 유용성을 구분하며 실제 참여·시간·효과는 별도 현장 증거로 남긴다.

기존 [references](../references.md)의 TutorMoments는 scaffold와 과도한 도움 평가의 외부 참고
후보다. 원 논문·데이터 revision, 이용 조건과 GrowWise에 대한 전이 가능성은 독립 검토 전이다.
기존 문서에 적힌 수치나 정책 사례를 검증된 보편 사실로 승격하지 않는다.

열린 조사: 부모가 준비 없이 실행할 수 있는가, 힌트가 정답을 대납하지 않는가, 유아의 말·그림·
몸짓을 충분히 허용하는가, 중·고 자료가 실제 추론을 요구하는가. synthetic editorial 회귀와
가정 현장 관찰을 구분하고 개인 기록은 이 위키에 보관하지 않는다.
