# Experiment record template

- Experiment ID, workstream and recorded date:
- Hypothesis and measurable acceptance/failure conditions:
- Source IDs, prior experiment IDs and `supersedes` relation:
- Status: planned / observed / failed / superseded:
- Repository revision and clean/modified working-tree condition:
- Synthetic fixture/dataset revision, sample size and selection method:
- Exact commands, seed, warmup, repeats and configuration:
- Model provider, model revision/digest, quantization and context/output limits (or not used):
- Generalized OS/architecture/CPU/RAM/VRAM and relevant tool versions:
- Observed date; public artifact path, content hash and retention/access conditions:
- Outcome including latency distribution, fallback mode and rubric failures:
- Failure analysis, alternate explanation, uncertainty and reproducibility limits:
- Privacy: confirm no real child history, identifiers, credentials or private paths:
- Child safety: non-diagnostic, age fit, source grounding, scaffold and parent review:
- Reviewer, acceptance state and next action:

Before execution keep environment/outcome/model revision `unknown` where necessary and status
`planned`. An executed ledger row requires an actual artifact, revision and environment. Link-only
private household evidence may be described generically in an operator handoff; never copy it here.
