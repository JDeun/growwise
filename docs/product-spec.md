# 제품 사양

## 개요

GrowWise는 **부모 중심의 Personal Education OS**를 지향한다. 범용 챗봇이나 AI 튜터가
아니라 다음 네 가지를 하나의 로컬 우선 시스템으로 연결한다.

1. **교육 트래킹** — 활동·관찰·관심·질문·어려움·회고를 장기적으로 기록
2. **자료 지식베이스** — 책·교육과정·체험·외부 자료를 provenance와 함께 수집·정리·검색
3. **학습자료 생성** — 현재 아이의 맥락과 부모의 목표에 맞는 활동/자료 생성
4. **부모 의사결정 지원** — 자연어 검색, 장기 변화 요약, 경험 균형 확인, 다음 활동 후보

LLM은 이 기능을 지원하는 **백그라운드 지능 계층**이다. 메인 제품 경험은 채팅이 아니라
기록·자료·활동·검색·검토·성장 맥락 관리다.

## 대상 연령과 단계별 역할

| 단계 | 연령 | 기준 | 역할 |
| --- | --- | --- | --- |
| 영아 | 0~2세 | 표준보육과정 등 | 부모 대면 놀이/상호작용·책 제안, 자유 관찰, 경험 커버리지. 비진단·비비교 |
| 유아 | 3~5세 | 누리과정 | 놀이형 활동·독서·탐방·수학 기초 자료 + 관찰 기록 |
| 초등 | 6~12세 | 초등 교육과정 | 과목/탐구/독서/글쓰기 자료 생성 + 과정 기록 |
| 중등 | 중학교 | 중학 교육과정 | 진도·오답·약점 가설·회고·자원·부모 지원 포인트 관리 |
| 고등 | 고등학교 | 고교 교육과정 | 학습 트래킹·회고·자료 관리·시험 대비 맥락 정리 |

첫 실사용은 현재 실제 가정에서 매일 검증 가능한 **영아(0~2세) 모드**다. 이는 제품의 최종
범위를 제한하지 않는다. 최종 목표는 전 연령·전 기능 완성이다.

## 핵심 제품 기능

### Child context

- 다자녀 프로필과 child scope
- stage/월령 band, 관심사, 언어/학습 맥락
- 실제 식별정보는 최소화하고 로컬에 저장

### Observation & learning log

- 부모가 선택한 의미 있는 관찰 기록
- 책/활동/체험과 연결
- 질문·과정·반응·어려움·재설명·다음 활동
- 기록 공백은 실패가 아니며 streak를 만들지 않음

### Resource knowledge base

- 책, 교육과정, 웹/공개 데이터, 부모 자료를 provenance와 함께 저장/색인
- 태그·주제·연령·교과·활동과 연결
- 자연어 검색/RAG

### Material generation

- 독서 활동지
- 영어 대화/표현 카드
- 탐방/여행 활동지
- 수학 놀이/연습 자료
- 과학 탐구 활동
- 글쓰기·말하기 활동
- 연령/단계별 부모 가이드

### Natural-language retrieval

자연어 입력은 chat-first UX가 아니라 **검색/명령 인터페이스**다.

예:

- "최근 한 달 신체 활동 기록만 찾아줘"
- "측정 관련 수학 활동을 마지막으로 한 게 언제야?"
- "최근 읽은 동물 주제 책과 연결된 활동을 정리해줘"
- "이 책과 현재 관심사를 연결해 내일 할 활동을 만들어줘"

답변은 가능한 경우 관련 내부 기록과 외부 source를 함께 보여준다.

### Parent Review

Parent Review는 사용자에게 상태 머신을 학습시키기 위한 화면이 아니라 내부 안전·감사 경계다.
기본 화면에서는 활동 내용을 확인한 뒤 **이 활동 사용하기** 한 번으로 사용 결정을 내린다.
직접 편집·수정 요청·사용 안 함과 세부 상태는 필요할 때만 고급 관리 영역에서 노출한다.

생성 자료의 내부 상태 흐름:

```text
DRAFT → REVIEW_PENDING
          ├─ REVISION_REQUESTED → DRAFT
          ├─ REJECTED
          └─ APPROVED → export/use
```

APPROVED 이전에는 최종 export/아이 사용 대상으로 처리하지 않는 것을 domain invariant로
강제한다.

## Desktop product IA

사용자에게 노출되는 desktop navigation은 9개 상위 workspace로 고정한다.

| Workspace | 책임 | 포함되는 하위 기능 |
| --- | --- | --- |
| 대시보드 | 현재 아이와 최근 상태 요약 | KPI, 최근 활동, 추천 활동 |
| 아이 프로필 | 아이 정보와 장기 맥락 | 학습 기록, 발달 분석, 성장 리포트 |
| 학습 기록 | 배움/관찰의 정본 기록 | 학습 기록, 관찰 기록, 중·고 학습 트래커 |
| 자료실 | 활동/근거 자료의 생성과 관리 | 활동 자료, 활동 관리, 참고 자료, 자료 찾기 |
| 사진첩 | 사진 중심 기록 | gallery, filter, detail, create/commit |
| 대화하기 | 기록·자료를 근거로 한 검색/후속 질문 | conversation history, answer, backup assist |
| 백업 및 복원 | 데이터 snapshot lifecycle | create/export/import/restore/history |
| 설정 | 앱/가족/개인정보 설정 | runtime status, profile edit, privacy delete |
| 도움말 | 사용법/원칙/문제 해결 | onboarding, AI/data policy, shortcuts |

관찰, 성장, 활동, discovery, library는 별도의 primary navigation이 아니라 위 상위 workspace의 subview다. legacy persisted route는 migration할 수 있지만 새 UI에서 다시 독립 sidebar 항목으로 노출하지 않는다.


## 교육 철학을 제품 요구사항으로

### 1. 측정은 허용하되 아이를 점수로 환원하지 않는다

시험 점수·정답률·학습 시간 같은 사실 데이터는 저장 가능하다. 그러나 이를 곧바로 전인적
능력 점수나 잠재력 등급으로 변환하지 않는다. 관찰, 측정, AI 해석을 데이터 구조와 UI에서
구분한다.

### 2. 성장 지도 = 경험 지도

성장 지도는 세 층의 projection을 제공한다.

- 전인 고정축: 신체, 정서/인성, 표현/예술, 사고/탐구, 사회성
- 학습 6축: 읽기, 말하기, 쓰기, 수학, 탐구, 사회성
- 연령 적응형 축: 영아 발달 영역 / 학령기 교과·역량

값은 **경험/관찰 커버리지**이며 성취 점수나 또래 비교가 아니다. UI는 가능하면 `최근 자주
경험함`, `새롭게 나타난 관심`, `최근 기록이 적음` 같은 질적 표현을 우선한다.

### 3. 최소 기록

모든 일상을 데이터화하지 않는다. 기록할 가치가 있는 사건을 부모가 선택한다. 기록량을
성과 지표로 만들지 않고, missing data를 부정적으로 해석하지 않는다.

### 4. 부모 검토와 인간 최종 판단

AI의 추천·요약·생성은 제안이다. 부모가 최종 판단한다. 특히 장기 기록에서 AI가 만든
패턴/가설은 원본 관찰과 분리해 표시한다.

### 5. 과도한 도움 경계

학령기 자료/코치 기능은 정답을 대신 주기보다 productive struggle을 남긴다. scaffold는
연령과 요청에 맞게 단계적으로 제공한다.

### 6. 아이 대면 챗봇 없음

GrowWise 자체에는 아이가 지속적으로 대화하는 AI companion/tutor를 두지 않는다. 아이가
외부 AI를 사용할 연령이 되면 GrowWise는 사용 원칙을 연습할 자료와 회고 기록을 제공할 수
있다.

### 7. 발달 비진단

영아/유아 관찰은 다음 활동과 부모 관찰을 돕기 위한 맥락이다. 정상/비정상 판정, 장애/질환
추정, 또래 percentile을 제공하지 않는다.

### 8. 근거가 철학보다 우선

제품은 부모의 철학을 일관되게 실행하도록 돕지만, 실제 관찰·검증 가능한 사실·신뢰 가능한
근거와 충돌할 때 철학을 사실처럼 강제하지 않는다. AI가 confirmation bias를 강화하지 않게
반대 관찰과 불확실성을 보존한다.

## 활동 퀘스트

퀘스트는 강제 과제가 아니라 **활동 초대**다.

- SUGGESTED / ACTIVE / COMPLETED / SKIPPED
- SKIPPED는 실패가 아님
- streak, XP, 벌점, 레벨업을 기본 기능으로 두지 않음
- 활동은 책·관심사·여행·최근 경험 커버리지에서 제안 가능

## 다자녀

모든 child-specific entity는 `child_id`로 분리한다. child switcher는 단순 UI 필터가 아니라
repository/RAG query scope 자체를 바꾼다. 형제 데이터 혼합은 안전 결함으로 취급한다.

## 영아 모드

영아 모드는 워크시트가 없다. 부모 대면 기능으로 구성한다.

- 월령 band에 맞는 놀이/상호작용 후보
- 책 읽어주기/보드북 자료 정리
- 부모의 짧은 자유 관찰 기록
- 기록 자동 태깅/정리
- 최근 경험 영역 요약
- 과거 관찰 자연어 검색
- 다음 활동 후보

영아의 행동을 상시 계측하거나 발달 진단으로 변환하지 않는다.

## 유아·초등 자료 생성

입력 → 관련 child context → 교육과정/자료 RAG → 생성 → 자동 평가 → 내부 Parent Review gate
→ 저장/export의 LangGraph workflow를 사용한다. Primary UX에서는 이 상태 머신 대신
**이 활동 사용하기**라는 한 번의 명시적 사용자 결정을 제공한다.

## 중·고 학습 트래킹

중·고등에서는 실제 측정 데이터가 더 중요해질 수 있다.

- 진도
- 오답/문제 유형
- 객관적 시험/연습 결과
- 어려움 메모
- 회고
- 자료/출처
- 관심과 장기 변화

`weakmap`은 고정 능력 판정이 아니라 **현재 기록에서 반복된 어려움에 대한 가설과 관련
근거의 지도**로 표현한다.

## 제품 성공 기준

GrowWise가 잘 작동한다는 것은 다음을 의미한다.

- 부모가 과거 기록을 쉽게 찾는다.
- 필요한 자료를 provenance와 함께 관리한다.
- 현재 아이 맥락에 맞는 자료를 빠르게 만든다.
- AI의 해석과 원본 사실을 구분할 수 있다.
- 장기간 사용해도 데이터가 소유 가능하고 이식 가능하다.
- 기록을 많이 하도록 압박하지 않는다.
- 아이를 점수/진단 대상으로 만들지 않는다.
- 부모가 실제 교육 판단에 더 좋은 맥락을 얻는다.
