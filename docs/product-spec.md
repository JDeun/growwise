# 제품 사양

## 개요

growwise는 세 겹의 사용자 가치를 가진다.

1. **자료 생성** — 입력(책·연령·목표·장소 등)을 받아 활동지·카드·질문·수업안을 만든다.
2. **학습 기록** — 활동 후 아이의 반응·어려움·흥미·다음 활동을 남긴다.
3. **부모 검토** — 아이에게 보여주기 전 난이도·민감성·개인정보를 점검한다.

주 사용자는 아이가 아니라 **부모(개인용)와 교사(기관용)**다.

> **현재 우선 목표: 개인이 운영하는 홈스쿨링용 데스크탑 앱.** 부모 한 명이 데스크탑에
> 설치해 쓰는 형태가 1차 목표다. 홈서버·상시 백엔드는 목표가 아니며, 기관용(어린이집·
> 유치원·학원) 확장은 그 뒤로 미뤄 둔다. 아래 기관용 내용은 나중 단계를 위한 참고다.

---

## 개인용 MVP

첫 버전은 **학습자료 생성기 + 학습 기록장** 정도가 적절하다.

### 핵심 기능

| 기능 | 입력 | 출력 |
| --- | --- | --- |
| 독서 활동지 생성 | 책 제목, 연령, 목표 | 질문, 어휘, 말하기 주제, 그림/쓰기 활동 |
| 영어 대화 카드 생성 | 일상 상황 | 짧은 영어 문장, 부모-아이 롤플레이, 반복 표현 |
| 탐방/여행 활동지 생성 | 장소, 역사 사건, 시설, 여행지 | 관찰 미션, 질문 |
| 수학 놀이 활동 생성 | 개념(수·패턴·분류·비교·측정·도형) | 놀이형 활동 |
| 글쓰기·말하기 코치 | 아이의 답변 | 다음 질문, 표현 확장, 다시 말하기 활동 |
| 학습 로그 저장 | 활동 결과 | 날짜·자료·반응·어려움·다음 활동(Markdown/DB) |
| 부모 검토 체크리스트 | 생성물 | 난이도·민감성·평가 압박·개인정보 노출 점검 |

### MVP 범위 원칙

- 단순한 라우터 하나로 입력 유형을 보고 해당 생성 모듈로 보낸다(멀티에이전트 지양).
- 인터넷 연결 없이도 기본 자료 생성과 기록 조회가 가능해야 한다.
- 출력은 부모가 바로 인쇄할 수 있는 품질(PDF)을 목표로 한다.

## 기관용 확장

잘 만들면 개인용 도구를 넘어 유치원·어린이집·학원·방과후 교실에서 쓰는
**교사용 AI 자료 제작 시스템**으로 발전할 수 있다. 기관용 포지셔닝은 아이 개인
튜터보다 **교사용 수업자료 제작 시스템**에 가깝다.

### 기관용 핵심 기능

- 연령별 활동지 생성
- 누리과정 및 초등 저학년 교육과정 매핑
- 주제별 수업안 생성
- 가정 연계 활동지 및 안내문 생성
- 학부모 피드백 문서 생성
- 아이 반응 관찰 기록 템플릿
- 반 전체 수준에 맞춘 난이도 조절
- 같은 주제를 언어·수학·과학·사회·미술·신체 활동으로 변환

## 제품화 3단계

| 단계 | 형태 | 중요 포인트 |
| --- | --- | --- |
| **1단계 (현재 목표)** | 개인용 데스크탑 앱 | 부모가 직접 쓰는 자료 생성과 학습 기록 |
| **2단계** | 교사용 자료 생성기 | 주제·연령·수업 시간·활동 목표 입력 → 수업안·활동지 |
| **3단계** | 어린이집·유치원·학원용 설치형/SaaS | 개인정보 보호, 원내 서버 배포, 교사 워크플로우, 학부모 커뮤니케이션 |

단계별로 재구조화 없이 성장하도록, 데이터 모델과 모듈 경계를 처음부터 개인용/기관용
공용으로 설계한다([data-model.md](data-model.md), [architecture.md](architecture.md) 참고).

## 비기능 요구사항

- **오프라인 우선**: 데스크탑 앱에서 인터넷 없이 기본 기능 사용 가능(외부 API는 선택적 보강)
- **인쇄 품질 출력**: 활동지 PDF는 교사·부모가 바로 인쇄 가능해야 함
- **개인정보 보호**: 아동 데이터 로컬 우선, 외부 전송 최소화([privacy-and-safety.md](privacy-and-safety.md))
- **확장성**: 새로운 과목·활동 유형을 생성 모듈 추가만으로 확장
