# 디자인 시스템

growwise의 시각 언어를 정의한다. 목표는 **따뜻하고 차분하며, 한눈에 읽히고, 접근성이
높은** 인터페이스다. 게임 UI의 **가독성(한눈에 파악)**은 빌리되, 게임의 자극적·압박적
연출은 쓰지 않는다([product-spec.md](product-spec.md) 게임화 프레이밍).

## 스타일 선택

UI 스타일 카탈로그(플랫·머티리얼·플루언트·글래스모피즘·뉴모피즘·미니멀·카드·다크모드
등) 중 growwise는 다음을 채택한다.

> **채택: 따뜻한 미니멀 + 소프트 카드(rounded) 기반**, 접근성 우선.

- **미니멀 / 플랫 기반**: 불필요한 장식 없이 콘텐츠·정보에 집중. 아이 기록과 활동이
  주인공이지 UI 효과가 아니다.
- **소프트 카드**: 둥근 모서리 + 부드럽고 낮은 그림자로 항목(퀘스트·기록·아이 카드)을
  구분. 딱딱하지 않고 따뜻하게.
- **머티리얼의 좋은 점만**: 그림자·계층으로 위계를 표현하되 과하지 않게. 디자인 토큰·
  접근성 규범을 참고.

**의도적으로 피하는 스타일 (이유 포함)**

- **뉴모피즘** — 저대비로 접근성이 나쁘다(아동·고령 부모 모두에게 불리).
- **글래스모피즘 / 강한 블러** — 대비·가독성 저하 + 블러는 성능 비용(오프라인·구형 기기
  목표와 충돌).
- **브루탈리즘 / 네오브루탈리즘** — 거칠고 압박적. 차분·따뜻함과 반대.
- **과한 그라데이션·네온 게임풍** — 자극·압박 연출로 사상(비압박)과 충돌.

## 디자인 원칙

1. **차분함 우선** — 색·모션·소리로 재촉하지 않는다. 알림은 부드럽게, 경고는 최소.
2. **가독성 우선** — 한눈에 읽히는 정보 위계. 성장 지도·퀘스트는 "게임처럼 명료하되"
   점수판·카운트다운 압박은 없음.
3. **접근성 필수** — 명도 대비 WCAG AA 이상, 색만으로 정보 전달 금지, 큰 터치/클릭 영역,
   또렷한 포커스, 모션 최소화 옵션 존중.
4. **비압박 시각 언어** — 큰 점수·등수·빨간 "실패" 배지·의무 스트릭·마감 경고음을 쓰지
   않는다. 성장은 긍정적·부드럽게 표현.
5. **인쇄 친화** — 활동지 출력물은 흑백 인쇄에도 또렷해야 한다(색 의존 금지, 충분한 여백).
6. **크로스플랫폼 조화** — Windows·macOS 양쪽에서 자연스럽게. OS 테마(라이트/다크)를 따른다.

## 디자인 토큰 (초안)

실제 값은 구현 시 조정. 라이트/다크 두 테마를 정의하고 OS 설정을 따른다.

### 색 (Light)

| 토큰 | 값(예시) | 용도 |
| --- | --- | --- |
| `--bg` | `#FBF9F6` | 따뜻한 오프화이트 배경 |
| `--surface` | `#FFFFFF` | 카드 표면 |
| `--ink` | `#2B2A28` | 본문 텍스트(대비 충분) |
| `--ink-soft` | `#6B6862` | 보조 텍스트 |
| `--primary` | `#2F8F6B` | 성장/새싹 그린(브랜드) |
| `--primary-soft` | `#E3F1EA` | 프라이머리 배경 톤 |
| `--accent` | `#E4A13A` | 따뜻한 강조(포인트) |
| `--info` | `#3B7DD8` | 정보 |
| `--attention` | `#D9903B` | 부드러운 주의(빨강 경보 대신 앰버) |
| `--border` | `#ECE7DF` | 경계선 |

> 색 규칙: **빨강은 파괴적/치명 오류 등 정말 필요한 곳에만.** "미완료·뒤처짐"을 빨강으로
> 낙인찍지 않는다(앰버·중립 톤 사용).

### 색 (Dark)

라이트의 역할을 유지하되 값만 교체: 배경 `#1E1D1B`, 표면 `#2A2825`, 본문 `#F1EDE6`,
프라이머리는 채도 낮춘 그린 등. 대비 AA 유지.

### 타이포그래피

- **글꼴**: 한글·라틴 겸용 **Pretendard**(SIL OFL, 오픈) 기본, 폴백 system-ui·sans-serif.
  코드/수치는 등폭(예: JetBrains Mono, OFL).
- **스케일(예)**: 12 / 14 / 16(본문) / 20 / 24 / 32. 줄간격 1.5 이상(가독성).
- 아동 대면 표시(성장 지도 등)는 더 크고 단순하게.

### 간격·모서리·그림자

- **간격**: 4px 배수 스케일(4·8·12·16·24·32).
- **모서리(radius)**: 카드 16, 버튼 10, 작은 요소 8(둥글고 부드럽게).
- **그림자**: 낮고 부드럽게(예: `0 1px 3px rgba(0,0,0,.06)`, 강조 카드 `0 4px 12px
  rgba(0,0,0,.08)`). 뉴모피즘식 이중 그림자 금지.

### 아이콘 · 일러스트

- 아이콘: **Lucide(ISC)** 또는 **Phosphor(MIT)** 등 오픈·라인 스타일(부드러운 굵기).
- 삽화가 필요하면 [integrations.md](integrations.md)의 CC0/CC-BY 소스(Openclipart 등).
- 라이선스는 [integrations.md](integrations.md) 방침(permissive)을 따른다.

## 핵심 컴포넌트 가이드

- **아이 전환(child switcher)**: 상단에 아이별 카드/아바타. 현재 아이가 명확히 강조.
- **성장 지도(방사형)**: 부드러운 채움, 축 라벨 또렷. **숫자 등급을 크게 박지 않음** —
  "많이 해본 영역"의 지도로 보이게. 3층 축은 탭/뷰 전환([product-spec.md](product-spec.md)).
- **활동 퀘스트 카드**: 제안→진행→완료 상태를 색+아이콘+텍스트(색만으로 구분 금지).
  완료는 긍정적 연출, 미완료는 중립(경고 아님). 마감 카운트다운·벌점 없음.
- **학습 기록(대화 로그)**: 읽기 쉬운 문서형. 질문·과정·관찰이 잘 드러나게.
- **부모 검토 화면**: 체크리스트가 명확하고, 승인/수정/폐기 동작이 분명.
- **상태 표시(빈/로딩/오류)**: 빈 상태는 다음 할 일을 안내(비난 아님), 오류는 침착한
  회복 안내(오프라인 시 "로컬로 계속 가능" 명시).

## 접근성 체크(요약)

- 텍스트 대비 AA(본문 4.5:1, 큰 텍스트 3:1) 이상.
- 색 + 아이콘/텍스트 병행(색맹 대응).
- 키보드 내비게이션·또렷한 포커스 링.
- `prefers-reduced-motion` 존중(모션 최소화).
- 확대(글꼴 스케일)에서 레이아웃 깨지지 않기.
