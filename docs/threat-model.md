# 위협 모델과 데이터 보존

아동 데이터를 다루는 로컬 우선 앱의 위협 모델. "로컬=안전"이라는 가정을 검증하고, 실제
유출 경로를 막는다.

## 보호 대상(자산)

- 아이의 **말·기록**(질문·풀이·재설명·부모 관찰 = 가장 민감)
- `child_profile`의 실명·연령·특이사항, 다자녀 관계
- **가족 위치**(탐방이 쓰는 집 주변 좌표)
- API 키·토큰

## 위협 경로와 대응

| 경로 | 위협 | 대응 |
| --- | --- | --- |
| **클라우드 동기화 폴더** | Documents/Desktop가 OneDrive·iCloud로 자동 동기화되어 아동 기록이 벤더로 유출 | 기본 OS app-data/계정 권한 + OS FileVault/BitLocker 경계. 사용자 선택 폴더의 동기화 여부는 직접 확인. 앱 자체 암호화는 미구현 |
| **원격 모델 프롬프트** | 원격 LLM 사용 시 아이의 말·기록이 외부로 전송 | [Model Provider 계약](privacy-and-safety.md): configured provider 명시 opt-in; Wiki/embedding local-only, photo 별도 opt-in. 호출별 동의창·전면 식별정보 리댁션은 미구현 |
| **내보내기(export)** | 백업·출력물에 아동 개인정보가 포함됨 | backup은 lossless 원본 snapshot, 인쇄는 승인 자료만. 내용·목적지 부모 검토 필요; 비식별 공유용 export는 미구현 |
| **저장소(git) 커밋** | 아동 PII가 공개 repo로 | `.gitignore` 광범위 차단 + 커밋 전 PII 스캔(별도 게이트) |
| **외부 콘텐츠 주입** | 웹·도서·지도에서 가져온 텍스트가 생성 프롬프트에 명령으로 작동(prompt injection) | 외부 콘텐츠는 **데이터로만 취급**, 지시로 해석 금지. 어댑터에서 정제 |
| **외부 API에 위치·식별정보** | 주변검색에 집 좌표가 식별정보로 전송 | 사용자 명시 좌표만 사용하고 아동 원문·집 위치 추론을 public adapter에 보내지 않음 |
| **로컬 추론 캐시** | 외부 추론 엔진이 입력을 디스크에 캐시 | 엔진 보관 설정과 OS 보호를 별도로 확인. GrowWise의 엔진 전체 캐시 비활성/암호화는 미구현 |
| **API 키 평문** | 앱 설정·백업·로그에서 키가 유출 | macOS Keychain/Windows Credential Manager 저장·원문 readback 없음·Core에만 적용·portable backup과 분리·환경변수 사용 해제 가능 |

## 데이터 보존·삭제

- **삭제권**: 특정 아이를 삭제하면 그 아이의 모든 기록·생성물·인덱스가 제거돼야 한다.
- **수명**: 0~고등까지 최대 ~18년 누적 → 보존 정책과 용량·백업 계획 필요.
- **백업/복구**: Markdown(SoT) 백업·버전관리 + SQLite 인덱스는 재생성. 손상 복구 절차.
- **최소 수집**: 기능에 불필요한 정보(생년·주소·연락처)는 애초 다루지 않는다.

저장 위치 이전 후 남은 원래 폴더와 과거 ZIP도 개인정보 사본이다. live purge는 현재 데이터
위치에만 적용되므로 완전 폐기 시 사본을 별도로 정리한다. OS 자격증명 저장소는 가족 공통
설정이며 child purge나 portable backup/restore에 포함되지 않는다.

미구현 선택 보호 기능의 범위·도입 조건은
[개인정보 문서](privacy-and-safety.md#아직-제공하지-않는-선택적-보호-기능)에 명시한다.

## 원칙

- "로컬"이 곧 "비공개"는 아니다 — 동기화·캐시·내보내기·원격 모델까지 봐야 진짜 로컬-우선.
- 아동 안전 앱이므로 **기본값이 가장 보수적**이어야 한다(원격·동기화·전송은 opt-in).
