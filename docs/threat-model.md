# 위협 모델과 데이터 보존

아동 데이터를 다루는 로컬 우선 앱의 위협 모델. "로컬=안전"이라는 가정을 검증하고, 실제
유출 경로를 막는다.

## 보호 대상(자산)

- 아이의 **말·기록**(질문·풀이·재설명·부모 관찰 = 가장 민감)
- `child_profile`의 실명·연령·특이사항, 다자녀 관계
- **가족 위치**(탐방이 쓰는 집 주변 좌표)
- API 키·토큰

## 위협 경로와 대응

| 경로 | 위협 | 대응 |
| --- | --- | --- |
| **클라우드 동기화 폴더** | Documents/Desktop가 OneDrive·iCloud로 자동 동기화되어 아동 기록이 벤더로 유출 | 데이터는 **동기화되지 않는 앱 전용 경로**(OS app-data)에 저장. 기본 위치 안내 + 선택적 at-rest 암호화 |
| **원격 모델 프롬프트** | 원격 LLM 사용 시 아이의 말·기록이 외부로 전송 | **Model Provider 프라이버시 계약**([privacy-and-safety.md](privacy-and-safety.md)): 호출당 명시 동의, 식별정보 리댁션, 원격 추론을 "경계 통제" 대상으로 |
| **내보내기(export)** | Markdown 묶음에 실명·관찰이 무검열로 나감 | 내보내기 시 리댁션 옵션 + 목적지 경고 |
| **저장소(git) 커밋** | 아동 PII가 공개 repo로 | `.gitignore` 광범위 차단 + 커밋 전 PII 스캔(별도 게이트) |
| **외부 콘텐츠 주입** | 웹·도서·지도에서 가져온 텍스트가 생성 프롬프트에 명령으로 작동(prompt injection) | 외부 콘텐츠는 **데이터로만 취급**, 지시로 해석 금지. 어댑터에서 정제 |
| **외부 API에 위치·식별정보** | 지오코딩/주변검색에 집 위치=식별정보 전송 | 좌표 coarsen 또는 사용자 입력 장소만, 탐방은 프라이버시 예외로 동의 |
| **로컬 추론 캐시** | STT/LLM이 프롬프트·오디오를 디스크에 캐시 | 캐시 위치·수명 점검, 민감 캐시 비활성/암호화 |
| **API 키 평문** | `.env` 평문 키 유출 | OS 키체인/자격증명 저장소 사용 권장 |

## 데이터 보존·삭제

- **삭제권**: 특정 아이를 삭제하면 그 아이의 모든 기록·생성물·인덱스가 제거돼야 한다.
- **수명**: 0~고등까지 최대 ~18년 누적 → 보존 정책과 용량·백업 계획 필요.
- **백업/복구**: Markdown(SoT) 백업·버전관리 + SQLite 인덱스는 재생성. 손상 복구 절차.
- **최소 수집**: 기능에 불필요한 정보(생년·주소·연락처)는 애초 다루지 않는다.

## 원칙

- "로컬"이 곧 "비공개"는 아니다 — 동기화·캐시·내보내기·원격 모델까지 봐야 진짜 로컬-우선.
- 아동 안전 앱이므로 **기본값이 가장 보수적**이어야 한다(원격·동기화·전송은 opt-in).
