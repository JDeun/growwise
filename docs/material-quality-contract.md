# 자료 초안 품질 경계

현재 생성 규칙 버전은 `growwise.material.v7`이다. AI가 반환한 `ActivityCoreDraft`의 실제
소제목·행동·질문을 Markdown으로 표시하고, 기존 사용자 정의 `MaterialDraft`도 같은 경계에서
다시 검증한다. 구조나 안전 검사를 맞추려고 질문·활동 내용을 임의로 추가하지 않는다.

검사는 AI 본문과 추가 부모 메모에 적용한다. 부모용 출판 양식에 있는 안전 문구나 참고자료가
부족한 AI 본문을 통과시키지 않는다. 안전 검사 실패, 구조 실패, 품질 실패, 호출 실패는 각각
구분된 fallback mode로 남으며 기존 기본 초안을 보존한다. 기본 초안과 AI 보강 결과 모두
부모의 명시적 사용 결정 전에는 최종 사용·인쇄 대상으로 승인하지 않는다.

## 결정적으로 검사하는 최소 계약

- 서로 다른 소제목 두 개, 실제 내용, 서로 다른 실행 행동 두 개와 질문이 있어야 한다.
  열린 질문을 생성하도록 요청하지만 자동 구조 검사는 물음표 유무를 확인하는 수준이다.
- 읽기·수학·과학·글쓰기·탐방은 해당 종류의 활동 목적이 실행 내용에 드러나야 한다.
  영어 카드는 실제 영어 표현을 포함해야 한다.
  일부 명확한 기초 인사의 잘못된 뜻 연결도 거절한다. 모든 번역과 문법을 판정하는 기능은 아니다.
  영어 질문에는 알맞은 짧은 응답도 예시로 보여 주도록 요청하며, 기초 대화 모델링을 정답 대납으로
  해석하지 않는다. 예시를 바탕으로 단어·역할·상황을 선택하는 활동을 지원한다.
- 중·고 활동에는 근거·가정·목적·독자·전략 등의 분석·판단 단서가 있어야 한다.
  영아에게 독립적인 읽기·문장 쓰기·정답 설명을 요구하지 않는다. 부모가 읽어 주는 활동은 허용한다.
  추가 부모 메모와 출판 후 전체 본문·교안에도 이 경계를 적용한다. 영아용 기본 교안은 보호자의
  시선·옹알이·몸짓 관찰, 기다리기·응답하기·중단하기로 구성하며 아기의 말·그림 답변을 요구하지 않는다.
  특정 소리·표정·동작이 나올 때까지 자극을 반복하라는 지시도 거절한다. 자발적 반응을 기다리거나
  보호자가 아이의 소리를 잠깐 따라 하는 것은 구분해 허용한다.
- 부모가 아이의 글·답을 대신 완성하거나 직접 고치는 지시, 무조건 피드백하지 말라는 지시는
  거절한다. 아이가 스스로 수정하도록 기다리는 지시와 부정형 보호 지시는 구분한다.
- 과학 활동의 초기 재료 관찰은 허용한다. 변화·실험 결과를 이미 관찰한 뒤 처음 예측하도록
  지시하는 순서는 거절한다. 과학 지침은 보이는 모습·들리는 소리·만져 느끼는 상태를 구분하도록
  요청하고, 실제 발견한 일부 감각 동사의 명확한 잘못된 연결도 거절한다. 변화나 소리가 없다는 관찰을
  허용한다. 모든 자연어 표현의 정확성을 판정하지는 않는다. 탐방 전 단계에서 실제 방문 결과를
  비교하도록 하지 않는다.
- 제공되지 않은 반려동물·부모 역할이나 특정 책 장면을 전제하는 일부 명확한 표현을 거절한다.
  부모가 제공한 주제·선택 근거와 조건부 예시는 구분한다.
- 개인정보·검토 우회·직접 답 제시 등의 기존 scaffold 검사는 추가 부모 메모에도 적용한다.
  영아의 별도 재료·행동 안전 검사도 계속 적용한다. 명시적으로 넣어 주거나 조작하게 하는
  분리 방울·구슬은 연령 적합한 일체형 장난감 안에 봉인된 조건이 분명하지 않으면 거절한다.
- 한글 어절 사이의 뜬금없는 CJK 문자 혼용을 제한적으로 거절한다. 원문·주제에 같은 표기가
  있거나 한자·중국어·일본어 학습 맥락이면 허용하며, 정상 한자 병기·고유명사·외국어 문장을
  일괄 금지하지 않는다. 전체 맞춤법·번역 검사 기능은 아니다.

`tests/test_material_observed_quality.py`는 보존된 실제 Qwen 4B 부족 출력 6종을 그대로 다시
검사한다. 과거 구조 통과 여부는 역사적 사실로 남기며, 현재 경계에서는 모두 기본 초안으로
대체된다. 기존에 부모 검토용으로 읽은 Gemma 5종·수정 영어 카드·수정 영아 활동도 그대로
다시 검사해 불필요한 거절을 방지한다. 과거 출력과 관측 조건은
[실제 생성물 기록](knowledge/experiments/model-typed-quality-20261103.md)에 남아 있다.
이 회귀 검사는 새 모델 실행 결과나 실제 교육 효과 실험으로 기록하지 않는다.

## 남는 한계와 부모 판단

이 검사는 보수적인 텍스트 계약 검사다. 모든 문장의 의미·사실·수량 관계·문법·학습 난이도를
판정하지 못하며, 새로운 표현의 결함을 놓치거나 정상 표현을 거절할 수 있다. 근거 식별자가
실제로 존재한다는 검사 역시 그 자료가 모든 생성 문장을 뒷받침한다는 증명은 아니다.
`llm_enhanced`는 이 경계를 통과했다는 생성 방식 표시이며 교육 품질 인증이나 모델 추천이 아니다.

AI를 사용하지 못하면 연령·종류에 맞는 기본 활동 구조와 준비·힌트·안전·되돌아보기 안내를
제공한다. 이는 임의 주제를 완성된 전문 수업으로 바꾸는 대체 모델이 아니다. 부모가 실제 책,
재료, 장소와 아이의 상태에 맞게 확인·수정해야 한다. 하드웨어 자동 모델 선택은 메모리 기반의
시작 설정이며 교육적 적합성 추천은 아니다. 모델·양자화·학령·주제가 바뀌면 실제 출력과
메모리를 다시 확인해야 한다.

[후속 반복 실측과 v7 재생 기록](knowledge/experiments/model-repeat-quality-20261103.md)은
모든 거절 출력, 최종 기본 초안, 버전별 실제 실행과 저장 응답 재생을 구분해 보존한다.
