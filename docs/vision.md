# 비전과 교육 철학

## 출발점

GrowWise는 범용 AI 챗봇을 만들기 위한 프로젝트가 아니다. 이미 ChatGPT, Claude 같은 상용
LLM이 일반 대화와 질의응답을 매우 잘 수행한다. GrowWise가 풀려는 문제는 다르다.

핵심 문제는 **부모가 자신의 교육 철학에 맞춰 아이의 성장과 학습을 장기적으로 추적하고,
흩어진 기록·책·교육과정·체험 자료를 정리하며, 필요할 때 적절한 학습 자료를 만들어 쓰는
과정이 어렵다**는 점이다.

따라서 GrowWise의 1차 목적은 다음 세 가지다.

1. **교육 트래킹과 관리** — 아이의 활동·관심·반응·질문·어려움·회고를 장기적으로 축적
2. **자료 수집·정리·검색** — 가족이 가진 기록과 외부 교육 자료를 provenance와 함께 연결
3. **필요한 자료 생성** — 현재 아이의 맥락과 부모의 목표에 맞는 학습 자료를 생성

LLM은 이 세 가지를 보조하는 **백그라운드 지능 계층**이다.

## 제품 모토

> **AI가 아이를 대신해 가르치는 것이 아니라, 부모가 자신의 교육 철학에 따라 아이를
> 이해하고 돕기 위해 필요한 기록·자료·맥락을 관리하도록 돕는다.**

GrowWise에서 중요한 것은 "AI와 얼마나 많이 대화했는가"가 아니라 다음과 같은 질문에
제품이 얼마나 잘 답하는가다.

- 최근 아이가 어떤 활동을 해왔는가?
- 무엇에 지속적으로 관심을 보였는가?
- 어떤 영역의 경험이 최근 적었는가?
- 이전 관찰과 지금의 반응 사이에 어떤 변화가 있는가?
- 지금 이 아이에게 해볼 만한 활동은 무엇인가?
- 이 책·여행지·주제를 어떻게 학습 활동으로 바꿀 수 있는가?
- 특정 기록이나 자료를 자연어로 빠르게 찾을 수 있는가?
- 답변과 생성 자료의 근거는 어디에서 왔는가?

## LLM은 화면의 주인공이 아니다

GrowWise의 LLM 사용은 기본적으로 **behind-the-scenes**다.

### LLM이 하는 일

- 기록 자동 분류·태깅·요약
- 관찰 기록에서 검색 가능한 메타데이터 추출
- 자연어 질의를 structured search/RAG query로 변환
- 여러 시점의 기록을 비교·요약
- 책·교육과정·외부 자료의 핵심 정보 정리
- 아이의 현재 맥락과 목표에 맞는 활동/학습자료 생성
- 생성 자료의 구조·연령 적합성·grounding 검토 보조
- 저장된 자료에 근거한 자연어 답변
- 다음 활동 후보 제안

### LLM이 하지 않는 일

- 아이에게 지속적으로 말을 거는 companion/chatbot
- 아이 대신 정답을 주는 자율 튜터
- 부모의 판단을 대체하는 의사결정자
- 발달 상태를 진단하거나 또래 대비 등급을 부여하는 평가자

자연어 입력창이나 검색 인터페이스는 존재할 수 있다. 하지만 이는 **chat-first UX**가 아니라
"데이터를 자연어로 다루는 인터페이스"다. 대화 자체가 제품의 목적이 아니다.

## 교육 철학

> 교육 사상의 상세 원칙은 [pedagogy.md](pedagogy.md)가 정본이다.

- 선행학습과 반복 문제풀이보다 읽기·말하기·쓰기·논리·비판적 사고·체험·예체능의 균형을
  중시한다.
- 점수보다 과정, 질문, 관심, 관찰, 자기 언어 재구성을 중시한다.
- 아이를 다른 아이와 비교하지 않고 **self-vs-self** 맥락에서 본다.
- AI는 정답 기계가 아니라 부모가 자료와 맥락을 다루기 위한 도구다.
- 학습은 책상 위 과제뿐 아니라 가족 대화, 책 읽기, 동네 탐방, 여행, 놀이, 신체·예술
  활동까지 포함한다.
- 부모가 최종 판단자이며, 생성 자료는 Parent Review 이후에 사용한다.

## 0세부터 고등학교까지

GrowWise는 한 시기의 학습 앱이 아니라 **장기적인 성장 기록 시스템**을 지향한다.

- **영아(0~2)**: 놀이·상호작용 제안, 책 읽어주기, 부모 관찰 기록, 경험 커버리지
- **유아(3~5)**: 놀이형 활동, 독서·탐방·수학 기초 자료 생성
- **초등**: 과목별 자료 생성, 질문·탐구·글쓰기 지원, 학습 기록
- **중·고**: 직접 가르치기보다 진도·약점·오답·회고·자원·부모 지원 포인트를 관리

첫 실사용 영역을 영아로 둔 이유는 현재 생후 9개월 아이에게 실제로 매일 사용할 수 있기
때문이다. 이 선택은 단순한 MVP 축소가 아니라 **실제 가정에서 장기 기록 시스템을 초기에
검증할 수 있는 dogfooding 전략**이다.

## 핵심 데이터는 "대화"보다 "맥락"

초기의 "학습 대화 기록장"이라는 표현은 일부만 맞다. GrowWise의 핵심 데이터는 더 넓다.

- 아이의 질문
- 활동과 시도 과정
- 부모 관찰
- 관심사 변화
- 읽은 책과 체험
- 어려웠던 지점
- 검증한 근거
- 자기 언어 재설명
- 활동의 provenance
- 다음 활동
- 경험 영역별 장기 커버리지

따라서 더 정확한 정의는 **교육 맥락 기록장 + 자료 지식베이스 + 생성 도구**다.

## 자연어 검색의 위치

자연어 질의응답은 중요한 기능이지만 별도 챗봇이 아니다.

예:

- "최근 한 달 동안 신체 활동 기록만 찾아줘"
- "수학에서 측정 관련 활동을 마지막으로 한 게 언제야?"
- "최근 읽은 책 중 동물 주제만 묶어줘"
- "탐구 활동이 적었던 기간과 당시 기록을 정리해줘"
- "이 책과 기존 관심사를 연결해서 내일 할 활동 만들어줘"

이 답변은 RAG와 structured query를 통해 **로컬 기록/허용된 외부 자료에 근거**해야 하며,
가능한 경우 출처와 관련 기록을 함께 보여준다.

## 제품 성공 기준

GrowWise가 성공했다는 것은 사용자가 AI를 많이 쓰는 것이 아니라 다음이 가능해졌다는 뜻이다.

1. 몇 년간의 교육 기록을 잃지 않고 축적할 수 있다.
2. 과거 자료와 관찰을 몇 초 안에 다시 찾을 수 있다.
3. 현재 아이의 맥락을 기억한 채 다음 활동을 준비할 수 있다.
4. 생성 자료가 부모의 교육 원칙과 연령에 맞는다.
5. 데이터가 특정 SaaS나 모델에 잠기지 않는다.
6. 부모가 아이의 성장을 점수 대신 장기적인 맥락으로 이해할 수 있다.

## 기술 철학

- **Local-first / offline-first**
- **Markdown ownership** + SQLite projection
- **LangChain + LangGraph**: 검색·생성·검토·복구 workflow
- 모델 공급자 독립성
- human-in-the-loop
- provenance/citation
- 개인정보 최소화
- 전 기능 구현 후 안정화·적대적 리뷰·위생까지 완료
