# 과목별 기준 자료와 보강 소스

현재 모인 자료는 철학과 시스템 방향을 잡기에는 충분하지만, 실제 교육 제품으로
만들려면 과목별 기준 자료와 외부 소스가 더 필요하다. 아래는 과목별로 필요한 기준,
보강 소스 후보, 구현 아이디어를 정리한 것이다.

> 외부 소스를 실제로 연동할 때는 각 소스의 **이용 약관·라이선스·저작권**을 개별
> 확인한다. 특히 도서 메타데이터, 지도, 이미지가 그렇다.

---

## 연령 단계별 교육과정 기준

대상이 0세~고등이므로([product-spec.md](product-spec.md) 대상 연령), 단계별 기준 문서가
다르다. 원문은 상업 이용 제한이 있을 수 있으니 **재배포하지 말고 성취기준 코드 매핑 +
자체 설명**으로 쓴다([integrations.md](integrations.md) NCIC 주의).

- **영아(0~2세)**: 제4차 어린이집 표준보육과정(0~2세 보육과정)
- **유아(3~5세)**: 누리과정
- **초등(6~12세)**: 초등학교 교육과정(국가교육과정, NCIC)
- **중등/고등**: 중학교·고등학교 교육과정(NCIC). 중·고는 자료 생성보다 진도·성취기준
  대비 **학습 트래킹**에 성취기준을 활용

아래 과목별 소스는 주로 유아~초등 자료 생성 기준이다.

## 수학 커리큘럼

**필요한 것**
- 연령별 수 감각, 연산, 도형, 측정, 패턴 순서
- 놀이형 수학 활동의 난이도 단계
- 아이 반응에 따른 다음 활동 추천 기준

**보강 소스**
- 국내 초등 수학 교육과정
- Khan Academy Kids
- CK-12
- OpenStax 초급 수학 자료
- 교사용 수학 활동지 공개 자료

**구현 아이디어**
- 놀이형 수학 활동 생성기
- 수학 개념별 단계표
- 활동 후 관찰 로그 기반 다음 활동 추천

## 국어 문해력

**필요한 것**
- 어휘, 듣기, 말하기, 읽기 이해, 쓰기 발달 기준
- 이야기 다시 말하기, 관찰문, 설명문, 이유 말하기 템플릿
- 책 기반 질문 난이도 조절 기준

**보강 소스**
- 누리과정
- 초등 국어 교육과정
- 국립국어원 공개 자료
- 공공도서관 추천도서 목록
- 독서교육종합지원시스템 참고 자료

**구현 아이디어**
- 책 기반 질문 생성
- 낱말 카드 생성
- 이야기 순서 맞추기
- 관찰문·설명문·비교문 템플릿

**보강 소스**

**구현 아이디어**

## 교사용·기관용 워크플로우

**필요한 것**
- 수업안 포맷
- 활동 목표
- 도입-전개-마무리 구조
- 가정 연계 문서
- 평가가 아닌 관찰 기록 루브릭

**보강 소스**
- 누리과정 해설서
- 유치원·어린이집 활동계획안 샘플
- 교육부 공개 자료
- 어린이집 보육과정 자료
- 현장 교사 인터뷰 또는 파일럿 피드백

**구현 아이디어**
- 주제·연령·시간·활동 유형 입력 후 수업안 자동 생성
- 같은 주제의 가정 연계 활동지 생성
- 아이 반응 관찰표 생성
- 반 전체 수준별 난이도 변환
