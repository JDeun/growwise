# 과목별 기준 자료와 보강 소스

현재 모인 자료는 철학과 시스템 방향을 잡기에는 충분하지만, 실제 교육 제품으로
만들려면 과목별 기준 자료와 외부 소스가 더 필요하다. 아래는 과목별로 필요한 기준,
보강 소스 후보, 구현 아이디어를 정리한 것이다.

> 외부 소스를 실제로 연동할 때는 각 소스의 **이용 약관·라이선스·저작권**을 개별
> 확인한다. 특히 도서 메타데이터, 지도, 이미지가 그렇다.

---

## 연령 단계별 교육과정 기준

대상이 0세~고등이므로([product-spec.md](product-spec.md) 대상 연령), 단계별 기준 문서가
다르다. 원문은 상업 이용 제한이 있을 수 있으니 **재배포하지 말고 성취기준 코드 매핑 +
자체 설명**으로 쓴다([integrations.md](integrations.md) NCIC 주의).

- **영아(0~2세)**: 2024 개정 표준보육과정(교육부고시 제2024-23호, 2025-03 시행)
- **유아(3~5세)**: 2019 개정 누리과정
- **초·중·고**: 2015/2022 개정 교육과정의 학년별 전환을 실제 학년과 기준일로 판별한다.
  2022 개정 교육과정의 2024 일부개정은 국가교육위원회고시 제2024-3호를 기준으로 한다.

### 교육과정 버전 자동 선택

`curriculum_versions.py`는 아이의 생년월일/학년과 생성 기준일을 사용해 실제 적용
교육과정 계열을 선택한다. 2022 개정 교육과정의 학년별 시행 시점은 다음과 같이 고정 테스트한다.

- 2024-03-01: 초1~2
- 2025-03-01: 초3~4, 중1, 고1
- 2026-03-01: 초5~6, 중2, 고2
- 2027-03-01: 중3, 고3

학년을 알 수 없고 같은 학교급에 2015/2022 과정이 함께 적용되는 전환기라면 한쪽을 임의로
선택하지 않는다. 이 경우 `transition-unresolved` provenance를 남겨 프로필의 학년 또는
생년월일 입력을 요구할 수 있게 한다.

구조화된 `GROWWISE_CURRICULUM_ENDPOINT`를 연결하면 캐시 TTL마다 최신 레코드를 다시
조회한다. 새 버전은 공식 도메인(NCIC/교육부/국가교육위원회/i-누리), 공식 고시 번호,
적용 시작일, 적용 학년이 모두 검증될 때만 자동 활성화된다. 스크래핑 결과 자체는 교재 기준으로
자동 승격하지 않는다.

또한 `.github/workflows/curriculum-watch.yml`이 매주 NCIC와 교육부 게시판에서 기존에 없는
개정 고시 후보를 탐지한다. 후보 발견은 검토 신호이며, 공식 적용 메타데이터가 검증되기 전까지
기존 교육과정 매핑을 자동 교체하지 않는다.

아래 과목별 소스는 주로 유아~초등 자료 생성 기준이다.

## 수학 커리큘럼

**필요한 것**
- 연령별 수 감각, 연산, 도형, 측정, 패턴 순서
- 놀이형 수학 활동의 난이도 단계
- 아이 반응에 따른 다음 활동 추천 기준

**보강 소스**
- 국내 초등 수학 교육과정
- Khan Academy Kids
- CK-12
- OpenStax 초급 수학 자료
- 교사용 수학 활동지 공개 자료

**구현 아이디어**
- 놀이형 수학 활동 생성기
- 수학 개념별 단계표
- 활동 후 관찰 로그 기반 다음 활동 추천

- 공공도서관 추천도서 목록
- 독서교육종합지원시스템 참고 자료

**구현 아이디어**

## 교사용·기관용 워크플로우

**필요한 것**
- 수업안 포맷
- 활동 목표
- 도입-전개-마무리 구조
- 가정 연계 문서
- 평가가 아닌 관찰 기록 루브릭

**보강 소스**
- 누리과정 해설서
- 유치원·어린이집 활동계획안 샘플
- 교육부 공개 자료
- 어린이집 보육과정 자료
- 현장 교사 인터뷰 또는 파일럿 피드백

**구현 아이디어**
- 주제·연령·시간·활동 유형 입력 후 수업안 자동 생성
- 같은 주제의 가정 연계 활동지 생성
- 아이 반응 관찰표 생성
- 반 전체 수준별 난이도 변환
